Modul 06 Angriff 3–4 h ★★★★★ Fortgeschritten

Kerberoasting

Cheat Sheets
Kerberos Hashcat
Lernziele
  • SPNs in der Domäne enumerieren
  • Service Tickets mit GetUserSPNs.py anfordern
  • TGS-Hashes ($krb5tgs$23$) mit Hashcat knacken
  • Angriff mit beliebigem Domain-User-Account durchführen
Hintergrund

Kerberoasting nutzt eine Design-Eigenschaft von Kerberos: Service Tickets werden mit dem NTLM-Hash des Service-Accounts verschlüsselt. Jeder authentifizierte Domänen-User darf Service Tickets anfordern.

Dadurch kann ein Angreifer mit einem niedrigprivilegierten Account Service Tickets für alle SPNs anfordern und offline knacken. Schwache Passwörter von Service-Accounts (oft seit Jahren ungeändert) sind das Hauptproblem.

Schlüsselkonzepte

SPNs finden und Tickets anfordern

Code anzeigen
python3 GetUserSPNs.py corp.local/user:pass -dc-ip DC_IP -request
python3 GetUserSPNs.py corp.local/user:pass -dc-ip DC_IP -outputfile kerberoast.txt

Knacken

Code anzeigen
hashcat -m 13100 kerberoast.txt /usr/share/wordlists/rockyou.txt
hashcat -m 13100 kerberoast.txt rockyou.txt -r rules/d3ad0ne.rule --force

Modus 13100 = Kerberos 5 TGS-REP etype 23 ($krb5tgs$23$).

Aufgabe

Führe einen vollständigen Kerberoasting-Angriff durch: finde SPNs, fordere Service Tickets an und knacke die Hashes. Eskaliere anschließend mit dem kompromittierten Service-Account.

Anforderungen
  1. Alle SPNs mit GetUserSPNs.py listen
  2. Service Tickets anfordern und als Hashcat-Input speichern
  3. Mindestens einen Hash knacken
  4. Mit kompromittiertem Account weitere Enumeration durchführen
Akzeptanzkriterien
  • TGS-Hash erfolgreich geknackt
  • Service-Account-Passwort im Klartext
  • Weiterer Zugriff mit Service-Account dokumentiert
