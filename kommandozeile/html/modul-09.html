Textverarbeitung: sed & awk

Cheat Sheets
bash
Lernziele
  • sed für Textersetzung und Transformation einsetzen
  • awk für strukturierte Textverarbeitung nutzen
  • Reguläre Ausdrücke in sed und awk anwenden
  • Komplexe Einzeiler für Log-Analyse schreiben
Hintergrund

sed (Stream Editor) bearbeitet Text Zeile für Zeile. Der häufigste Befehl: s/alt/neu/ (Substitution). sed -i bearbeitet Dateien in-place. Mit -n und p kann man gezielt Zeilen ausgeben. sed ist ideal für einfache Ersetzungen und Löschungen in Scripts.

awk ist eine vollständige Skriptsprache für Textverarbeitung. Es verarbeitet Dateien Zeile für Zeile, teilt sie in Felder ($1, $2, ... $NF) auf. NR ist die aktuelle Zeilennummer, NF die Anzahl Felder. BEGIN{} und END{} Blöcke laufen vor/nach der Verarbeitung. awk wird täglich für Log-Analyse, CSV-Verarbeitung und Formatierung verwendet.

Schlüsselkonzepte

sed Grundlagen

Code anzeigen
# Substitution
sed "s/alt/neu/" datei.txt          # erste Fundstelle
sed "s/alt/neu/g" datei.txt         # alle Fundstellen
sed -i "s/alt/neu/g" datei.txt      # in-place
sed "s/alt/neu/gI" datei.txt        # case-insensitive

# Zeilen filtern
sed -n "5,10p" datei.txt            # Zeilen 5-10
sed -n "/Error/p" datei.txt         # Zeilen mit "Error"
sed "/^#/d" datei.txt               # Kommentare löschen
sed "/^$/d" datei.txt               # leere Zeilen löschen

# Mehrere Befehle
sed -e "s/foo/bar/" -e "/^#/d" datei.txt

awk Grundlagen

Code anzeigen
# Felder ausgeben
awk '{print $1}' datei.txt          # erstes Feld
awk '{print $NF}' datei.txt         # letztes Feld
awk -F: '{print $1, $3}' /etc/passwd  # mit Trenner

# Bedingungen
awk '{if ($3 > 100) print $1, $3}' datei.txt
awk '$3 > 100 {print}' datei.txt   # Kurzform

# Aggregation
awk '{sum += $1} END {print sum}' zahlen.txt
awk 'END {print NR " Zeilen"}' datei.txt

# Log-Analyse: IP-Zählung
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10

awk '{print $1}' access.log | sort | uniq -c | sort -rn ist die Standard-One-Liner für Web-Server-Log-Analyse — ermittelt die aktivsten IP-Adressen in Sekunden.

Aufgabe

Analysiere einen Apache-Access-Log mit awk: ermittle die Top-10-IPs, häufigste HTTP-Status-Codes und die meistabgerufenen URLs. Nutze sed, um IP-Adressen zu anonymisieren.

Anforderungen
  1. sed: 5 verschiedene Substitutions-Muster anwenden
  2. sed -n: gezielt Zeilen aus Logs extrahieren
  3. awk: Felder mit -F trennen und ausgeben
  4. awk: Aggregation (Summe, Zählung) berechnen
  5. Log-Analyse-Einzeiler für Top-IPs schreiben
Akzeptanzkriterien
  • Log-Analyse mit awk korrekt durchgeführt
  • sed für Texttransformation angewendet
  • Top-10-IP-Analyse korrekt erstellt
