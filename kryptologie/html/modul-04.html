Hintergrund

RSA (Rivest, Shamir, Adleman, 1977) basiert auf dem Faktorisierungsproblem: es ist einfach, zwei große Primzahlen zu multiplizieren, aber praktisch unmöglich, das Produkt wieder zu faktorisieren.

Diffie-Hellman (1976) löste ein fundamentales Problem: wie einigen sich zwei Parteien auf einen gemeinsamen geheimen Schlüssel, ohne sich jemals getroffen zu haben? Die Antwort liegt in der Einwegfunktion der Potenzierung modulo einer Primzahl.

Schlüsselkonzepte

RSA mit Python cryptography

Code anzeigen
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

# Schlüsselpaar generieren
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048
)
public_key = private_key.public_key()

# Verschlüsseln (mit Public Key)
ciphertext = public_key.encrypt(
    b"Geheime Nachricht",
    padding.OAEP(
        mgf=padding.MGF1(hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)

# Entschlüsseln (mit Private Key)
plaintext = private_key.decrypt(ciphertext, padding.OAEP(
    mgf=padding.MGF1(hashes.SHA256()),
    algorithm=hashes.SHA256(), label=None
))
print(plaintext)

openssl RSA

Code anzeigen
# Schlüsselpaar generieren
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private.pem
openssl rsa -in private.pem -pubout -out public.pem

# Verschlüsseln / Entschlüsseln
openssl rsautl -encrypt -pubin -inkey public.pem -in msg.txt -out msg.enc
openssl rsautl -decrypt -inkey private.pem -in msg.enc -out msg.dec

ECDH Schlüsselaustausch

Code anzeigen
from cryptography.hazmat.primitives.asymmetric.x25519 import X25519PrivateKey

# Alice
alice_private = X25519PrivateKey.generate()
alice_public = alice_private.public_key()

# Bob
bob_private = X25519PrivateKey.generate()
bob_public = bob_private.public_key()

# Gemeinsames Geheimnis
alice_shared = alice_private.exchange(bob_public)
bob_shared = bob_private.exchange(alice_public)

assert alice_shared == bob_shared  # identisch!
Aufgabe

Implementiere ein RSA-basiertes Nachrichtensystem: Generiere Schlüsselpaare für Alice und Bob, verschlüssele eine Nachricht von Alice mit Bobs Public Key, entschlüssele sie mit Bobs Private Key. Implementiere zusätzlich ECDH.

Anforderungen
  1. RSA-Schlüsselpaar (≥ 2048 Bit) generiert
  2. Verschlüsselung mit Public Key funktioniert
  3. Entschlüsselung mit Private Key gibt Original zurück
  4. ECDH ergibt identischen Shared Secret bei beiden Parteien
Akzeptanzkriterien
  • plaintext == original_message
  • ECDH shared secrets beider Parteien sind identisch
  • Versuch, Bobs Nachricht ohne Private Key zu lesen, schlägt fehl
