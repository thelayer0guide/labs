Symmetrische Verschlüsselung

Cheat Sheets
python openssl
Lernziele
  • AES als Standard für symmetrische Verschlüsselung verstehen
  • Betriebsmodi ECB, CBC und GCM unterscheiden
  • Padding und Initialisierungsvektor (IV) korrekt einsetzen
  • Dateien mit Python cryptography-Bibliothek verschlüsseln
  • Fehler beim Einsatz von Betriebsmodi erkennen (ECB-Pinguin)
Hintergrund

AES (Advanced Encryption Standard) ist seit 2001 der NIST-Standard für symmetrische Verschlüsselung. Mit 128, 192 oder 256 Bit Schlüssellänge ist es bei korrekter Anwendung praktisch unknackbar.

Die Wahl des Betriebsmodus ist entscheidend: ECB ist unsicher (gleiche Blöcke → gleiche Chiffrate, erkennbare Muster). CBC ist besser, aber anfällig für Padding-Oracle-Angriffe. GCM ist die moderne Wahl: Verschlüsselung + Authentizität in einem.

Schlüsselkonzepte

AES-GCM Verschlüsselung

Code anzeigen
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os

def encrypt(key: bytes, plaintext: bytes, aad: bytes = b"") -> tuple[bytes, bytes]:
    nonce = os.urandom(12)   # 96-Bit Nonce für GCM
    aesgcm = AESGCM(key)
    ciphertext = aesgcm.encrypt(nonce, plaintext, aad)
    return nonce, ciphertext

def decrypt(key: bytes, nonce: bytes, ciphertext: bytes, aad: bytes = b"") -> bytes:
    aesgcm = AESGCM(key)
    return aesgcm.decrypt(nonce, ciphertext, aad)

key = AESGCM.generate_key(bit_length=256)
nonce, ct = encrypt(key, b"Geheime Nachricht", b"header")
print(decrypt(key, nonce, ct, b"header"))

ECB vs. CBC — der Pinguin-Effekt

Code anzeigen
# ECB: gleiche Blöcke → gleiche Chiffrate → Muster sichtbar!
# Demonstration mit openssl:
openssl enc -aes-256-ecb -in bild.bmp -out bild_ecb.bmp -K $(openssl rand -hex 32)
# Ergebnis: Konturen des Bildes sind erkennbar

# CBC mit IV:
openssl enc -aes-256-cbc -in bild.bmp -out bild_cbc.bmp \
  -K $(openssl rand -hex 32) -iv $(openssl rand -hex 16)
# Ergebnis: Zufälliges Rauschen — kein erkennbares Muster
Aufgabe

Implementiere eine AES-GCM-Verschlüsselungsfunktion die Dateien ver- und entschlüsselt. Demonstriere den ECB-Pinguin-Effekt mit einem Bitmap-Bild.

Anforderungen
  1. AES-GCM Encrypt/Decrypt implementiert
  2. Datei-Verschlüsselung funktioniert
  3. ECB-Schwäche mit Bild demonstriert
  4. Nonce wird für jede Verschlüsselung neu generiert
Akzeptanzkriterien
  • Entschlüsselter Text ist identisch mit Original
  • ECB-verschlüsseltes Bild zeigt erkennbare Muster
  • GCM-verschlüsseltes Bild zeigt kein Muster
  • Falscher AAD oder manipulierter Ciphertext wird abgelehnt (GCM-Authentizität)
