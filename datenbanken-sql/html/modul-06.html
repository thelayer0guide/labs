Aggregation & GROUP BY

Cheat Sheets
bash
Lernziele
  • Aggregatfunktionen COUNT, SUM, AVG, MIN, MAX anwenden
  • GROUP BY für gruppierte Auswertungen nutzen
  • HAVING für Filterung nach Aggregation einsetzen
  • Subqueries für komplexe Abfragen verwenden
Hintergrund

Aggregatfunktionen berechnen Werte über eine Gruppe von Zeilen. COUNT(*) zählt alle Zeilen, COUNT(spalte) zählt Nicht-NULL-Werte. SUM, AVG, MIN, MAX wie erwartet. GROUP BY gruppiert Zeilen nach einem oder mehreren Feldern — jede Gruppe wird durch eine Ausgabezeile repräsentiert.

HAVING filtert Gruppen (nach GROUP BY), WHERE filtert Einzelzeilen (vor GROUP BY). Subqueries (Unterabfragen) verschachteln SELECT-Statements. Korrelierte Subqueries referenzieren die äußere Abfrage. Im Security-Kontext: Aggregation in SQLi ermöglicht das Extrahieren statistischer Information über Tabellenstruktur und Daten.

Schlüsselkonzepte

Aggregation in SQL

Code anzeigen
-- Einfache Aggregation
SELECT COUNT(*) AS anzahl FROM benutzer;
SELECT SUM(betrag) AS gesamtumsatz FROM bestellungen;
SELECT AVG(betrag) AS durchschnitt FROM bestellungen;
SELECT MAX(betrag), MIN(betrag) FROM bestellungen;

-- GROUP BY
SELECT benutzer_id, COUNT(*) AS bestellanzahl, SUM(betrag) AS umsatz
FROM bestellungen
GROUP BY benutzer_id
ORDER BY umsatz DESC;

-- HAVING (Filter nach GROUP BY)
SELECT benutzer_id, SUM(betrag) AS umsatz
FROM bestellungen
GROUP BY benutzer_id
HAVING umsatz > 1000;

-- Subquery
SELECT * FROM benutzer
WHERE id IN (SELECT benutzer_id FROM bestellungen WHERE betrag > 500);
Aufgabe

Analysiere eine Bestelldatenbank: Top-10-Kunden nach Umsatz, Durchschnittsbetrag pro Monat, Kunden mit mehr als 5 Bestellungen.

Anforderungen
  1. COUNT, SUM, AVG, MAX, MIN auf reale Daten anwenden
  2. GROUP BY mit ORDER BY kombinieren
  3. HAVING vs. WHERE: Unterschied erklären und demonstrieren
  4. Subquery für IN-Bedingung nutzen
  5. Monatsweise Aggregation mit strftime/DATE_FORMAT
Akzeptanzkriterien
  • Aggregations-Auswertungen korrekt
  • HAVING korrekt eingesetzt
  • Top-10-Kunden korrekt ermittelt
