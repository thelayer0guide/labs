JOINs: INNER, LEFT, RIGHT

Cheat Sheets
bash
Lernziele
  • INNER JOIN, LEFT JOIN und RIGHT JOIN verstehen und anwenden
  • Kartesisches Produkt (CROSS JOIN) kennen
  • Multi-Table JOINs formulieren
  • JOIN-Performance und Indizes einschätzen
Hintergrund

JOINs verbinden Daten aus mehreren Tabellen. INNER JOIN gibt nur Zeilen zurück, die in beiden Tabellen eine Übereinstimmung haben. LEFT JOIN gibt alle Zeilen aus der linken Tabelle zurück — fehlende rechte Werte werden mit NULL gefüllt. RIGHT JOIN ist das Spiegelbild. FULL OUTER JOIN kombiniert beide.

Im Security-Kontext ermöglichen JOINs in SQL-Injection UNION-Angriffe, die Daten aus anderen Tabellen (z.B. users, credentials) extrahieren. Verständnis von JOIN-Logik hilft beim Formulieren von SQLi-Payloads und beim Verstehen von Datenbankstruktur aus Fehlermeldungen.

Schlüsselkonzepte

JOIN-Abfragen

Code anzeigen
-- INNER JOIN (nur Matches)
SELECT b.name, be.betrag, be.datum
FROM benutzer b
INNER JOIN bestellungen be ON b.id = be.benutzer_id;

-- LEFT JOIN (alle Benutzer, auch ohne Bestellung)
SELECT b.name, COUNT(be.id) AS anzahl_bestellungen
FROM benutzer b
LEFT JOIN bestellungen be ON b.id = be.benutzer_id
GROUP BY b.id, b.name;

-- Benutzer OHNE Bestellung
SELECT b.name
FROM benutzer b
LEFT JOIN bestellungen be ON b.id = be.benutzer_id
WHERE be.id IS NULL;

-- Drei-Tabellen-JOIN
SELECT b.name, p.name AS produkt, bp.menge
FROM benutzer b
JOIN bestellungen be ON b.id = be.benutzer_id
JOIN bestellpositionen bp ON be.id = bp.bestell_id
JOIN produkte p ON bp.produkt_id = p.id;
Aufgabe

Schreibe JOINs auf einem E-Commerce-Schema: alle Benutzer mit Bestellanzahl (LEFT JOIN), alle Bestellungen mit Produkten (INNER JOIN), Benutzer ohne Bestellung.

Anforderungen
  1. INNER JOIN: Definition und Venn-Diagramm erklären
  2. LEFT JOIN: Benutzer ohne Bestellungen finden
  3. Drei-Tabellen-JOIN mit Zwischentabelle (n:m)
  4. CROSS JOIN: Kartesisches Produkt erläutern
  5. Unterschied JOIN-Typen in Venn-Diagrammen skizzieren
Akzeptanzkriterien
  • INNER JOIN korrekt formuliert
  • LEFT JOIN inkl. NULL-Check korrekt
  • Drei-Tabellen-JOIN ausgeführt
