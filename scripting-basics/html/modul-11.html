Skript-Sicherheit & Best Practices

Cheat Sheets
bash python
Lernziele
  • Command-Injection in Skripten vermeiden
  • Secrets sicher aus Umgebungsvariablen lesen
  • Input-Validierung in Skripten implementieren
  • ShellCheck für Bash und Bandit für Python nutzen
Hintergrund

Skripte können selbst Sicherheitslücken haben. Command-Injection in Bash: wenn Benutzereingaben direkt in Shell-Befehle eingebaut werden. Beispiel: eval "$BENUTZEREINGABE" oder grep "$BENUTZEREINGABE" datei — wenn BENUTZEREINGABE Shellcode enthält, wird dieser ausgeführt. Gegenmaßnahme: Eingaben in doppelte Anführungszeichen, nie eval mit Benutzereingaben.

Secrets in Skripten: NIEMALS Passwörter, API-Keys oder Tokens im Code oder als Argument. Stattdessen: Umgebungsvariablen (os.environ.get, $VAR in Bash), Secrets-Manager (AWS Secrets Manager, HashiCorp Vault), .env-Datei (nie committen, via python-dotenv laden). ShellCheck analysiert Bash-Skripte auf häufige Fehler. Bandit scannt Python-Code auf Sicherheitsprobleme. Beide sind in CI/CD integrierbar.

#!/bin/bash
# UNSICHER: Command-Injection
# DATEINAME="$(read -p "Datei: " n; echo $n)"
# grep "$DATEINAME" /var/log/auth.log  # GEFAEHRLICH!

# SICHER: Validierung und Quoting
lese_datei() {
    local datei="$1"
    if [[ ! "$datei" =~ ^[a-zA-Z0-9._-]+$ ]]; then
        echo "FEHLER: Ungueltige Zeichen im Dateinamen" >&2
        exit 1
    fi
    if [[ ! -f "/var/log/$datei" ]]; then
        echo "FEHLER: Datei nicht gefunden" >&2
        exit 1
    fi
    grep "" "/var/log/$datei"  # Korrekt gequotet
}

# Secrets aus Umgebungsvariablen
API_KEY="${API_KEY:?API_KEY Umgebungsvariable nicht gesetzt}"

# Python: Bandit
# pip install bandit
# bandit -r ./scripts/ -ll  # Nur Medium+ Severity

# ShellCheck
# apt install shellcheck
# shellcheck mein_skript.sh

# subprocess SICHER
import subprocess
def sichere_suche(suchbegriff):
    if not suchbegriff.replace("-","").isalnum():
        raise ValueError("Ungueltige Zeichen")
    return subprocess.run(
        ["grep", "-r", suchbegriff, "/var/log"],
        capture_output=True, text=True, timeout=30
    )
