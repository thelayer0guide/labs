Type Hints & CLI-Tools

Type Hints · Dataclasses · argparse · Typer · Rich

Hintergrund

Type Hints machen Python-Code wartbarer — nicht weil sie Laufzeitfehler verhindern (tun sie nicht), sondern weil IDEs und mypy damit Fehler vor der Ausfuehrung finden. @dataclass eliminiert Boilerplate-Konstruktoren und macht Datenklassen auf einen Blick lesbar.

Rich verwandelt einfache print()-Ausgaben in formatierte Terminal-UIs mit Tabellen, Farben und Fortschrittsbalken — mit einem einzigen Import.

Monatsprojekt Vollstaendig typisiertes TODO-CLI

Baue ein todo-CLI-Tool mit vier Subcommands. Persistenz via JSON-Datei. Vollstaendige Type Hints — mypy --strict muss fehlerfrei durchlaufen. Ausgabe mit rich.table.

  • @dataclass class Todo: id, title, done, created_at — alle typisiert
  • Subcommands: add TITLE, list, done ID, delete ID
  • Persistenz: laden/speichern als JSON via json.load / json.dump
  • mypy --strict todo/ gibt 0 Fehler
  • list gibt Tabelle mit rich.table.Table aus — erledigte Items durchgestrichen
  • Ungueltiger ID gibt Fehlermeldung auf stderr + Exit-Code 1
Akzeptanzkriterien
python -m todo add 'Monat 7 anfangen'
python -m todo add 'README schreiben'
python -m todo list
# Tabelle mit ID, Titel, Status
python -m todo done 1
python -m todo list  # -> Eintrag 1 durchgestrichen
mypy --strict todo/
# Success: no issues found
