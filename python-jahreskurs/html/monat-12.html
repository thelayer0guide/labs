Hintergrund

Das Abschlussprojekt ist mehr als die Summe der vorherigen Monate: Es ist das erste Mal, dass du ein Problem von Anfang bis Ende selbst definierst, architektierst und implementierst. Die Wahl des Themas ist sekundaer — was zaehlt ist die Qualitaet: Type Hints, Tests, saubere Struktur, dokumentiertes CLI.

Drei moegliche Richtungen: CLI-Tool (Admin-Automatisierung, Datenverarbeitung), Web-API (FastAPI + Datenbank), TUI (Terminal-UI mit Textual oder Rich). Alle drei haben denselben Qualitaets-Anspruch.

Monatsprojekt Abschlussprojekt — Freie Wahl

Entwickle ein vollstaendiges Python-Projekt deiner Wahl. Mindestanforderungen an Qualitaet gelten unabhaengig vom Thema. Dokumentiere Architekturentscheidungen in einer ARCHITECTURE.md.

  • Vollstaendige Type Hints — mypy --strict gibt hoechstens 5 Fehler
  • Test-Coverage > 70 % — mindestens 15 Tests
  • ruff check . gibt 0 Fehler
  • README mit: Beschreibung, Voraussetzungen, Installation, Usage, Beispiele
  • Mindestens 3 von: OOP, Persistenz, Netzwerk, Concurrency, CLI, Web-API
  • pip install -e . installiert Projekt — Entrypoint funktioniert
Akzeptanzkriterien
pip install -e .
myprojekt --help
# zeigt alle Subcommands und Argumente

mypy src/ --strict
