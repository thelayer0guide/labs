W 25
sqlite3 Grundlagen
  • sqlite3.connect(), cursor(), execute(), commit()
  • CREATE TABLE, INSERT, SELECT, UPDATE, DELETE
  • Parameterized queries (?) — SQL Injection verhindern
  • fetchone(), fetchall(), fetchmany()
  • row_factory = sqlite3.Row für dict-ähnlichen Zugriff
  • In-Memory-DB: ":memory:" für Tests
import sqlite3 from contextlib import closing with sqlite3.connect("kontakte.db") as conn: conn.row_factory = sqlite3.Row with closing(conn.cursor()) as cur: cur.execute("SELECT * FROM kontakte WHERE name LIKE ?", ("%Ada%",)) for row in cur.fetchall(): print(dict(row))
