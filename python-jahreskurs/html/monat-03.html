Monat 03

Dateiarbeit & Stdlib

File I/O · pathlib · json · csv · datetime · Module

Hintergrund

Dateien sind das universelle Interface: Logdateien, Konfigurationen, Daten-Exporte — fast jedes Admin-Skript liest oder schreibt Dateien. pathlib.Path macht das plattformubergreifend und ausdrucksstark. Der wichtigste Grundsatz: immer den Context Manager (with open(...)) verwenden — er schliesst Dateien auch bei Exceptions zuverlaessig.

json und csv aus der Standardbibliothek decken 90 % aller strukturierten Datenformate ab, ohne ein einziges Drittpaket. datetime liefert Zeitstempel fuer Logs und Reports.

Monatsprojekt Verzeichnis-Organizer

Schreibe ein CLI-Tool, das ein Verzeichnis analysiert, Dateien nach Endung gruppiert und einen JSON-Report mit Zeitstempel speichert. Pfad per sys.argv[1], Default: aktuelles Verzeichnis.

  • pathlib.Path.rglob() fuer rekursives Scannen
  • Gruppierung als dict[str, list[str]] — Schluessel ist die Dateiendung
  • Gesamt-Groesse in Bytes berechnen (stat().st_size)
  • Report als report_YYYY-MM-DD.json speichern (datetime.date.today())
  • Nicht lesbare Dateien ueberspringen und separat zaehlen
  • Report enthaelt: Pfad, Datum, Dateianzahl, Gesamtgroesse, Aufschluesselung nach Typ
Akzeptanzkriterien
python file_organizer.py /etc
# -> report_2026-06-19.json erzeugt

python -c "import json; d=json.load(open('report_2026-06-19.json')); print(list(d.keys()))"
# ['path', 'date', 'total_files', 'total_bytes', 'by_extension']
