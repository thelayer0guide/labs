Hintergrund

Netzwerksicherheit schützt die Infrastruktur durch Kontrolle des Datenverkehrs. Firewall-Typen: Packet Filter (Layer 3/4, Regeln auf IP/Port), Stateful (merkt sich Verbindungsstatus), Application-Layer (Layer 7, versteht Protokolle), NGFW (Next-Gen, Kombination mit IPS, DPI). WAF (Web Application Firewall) schützt speziell HTTP/HTTPS-Anwendungen (Cloudflare, ModSecurity).

IDS (Intrusion Detection System) erkennt Angriffe und meldet sie. IPS (Intrusion Prevention System) erkennt und blockiert. DMZ (Demilitarized Zone) ist ein Netzwerksegment zwischen Internet und internem Netz — öffentlich zugängliche Server (Webserver, Mail) werden hier platziert. Network Segmentation teilt das interne Netz in Zonen auf: Trennung von OT, IoT, Admin-Netz, Gast-WLAN reduziert die Angriffsfläche erheblich.

Schlüsselkonzepte

Firewall & Netzwerk-Tools

Code anzeigen
# iptables (Linux-Firewall)
iptables -L -v -n          # Regeln anzeigen
iptables -A INPUT -p tcp --dport 22 -j ACCEPT  # SSH erlauben
iptables -A INPUT -p tcp --dport 80 -j ACCEPT  # HTTP erlauben
iptables -A INPUT -j DROP  # Rest ablehnen

# UFW (vereinfachtes iptables)
ufw status verbose
ufw allow ssh
ufw allow 80/tcp
ufw deny 23/tcp  # Telnet blockieren
ufw enable

# nftables (modernes iptables)
nft list ruleset

# Firewall-Regeln testen
nmap -p 22,80,443,8080 192.168.1.1
nmap --script firewall-bypass 192.168.1.1

# Netzwerk-Monitoring
tcpdump -i eth0 -n         # Paket-Sniffer
tcpdump -i eth0 port 80 -w capture.pcap  # Aufzeichnen
tshark -r capture.pcap     # Analyse
Aufgabe

Konfiguriere eine UFW-Firewall auf einem Linux-System: erlaube SSH und HTTP, blockiere alles andere. Teste die Regeln mit nmap.
