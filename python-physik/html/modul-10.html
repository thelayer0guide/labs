Partikel-Systeme & Kraftfelder

Cheat Sheets
python
Lernziele
  • Einen Partikel-Emitter mit konfigurierbarer Spawn-Rate implementieren
  • Partikel-Lebensdauer mit Fade-Out und Auto-Destroy umsetzen
  • Kraftfelder (Gravitation, Wind, Explosion) auf Partikel anwenden
  • Effiziente Partikel-Verwaltung mit In-Place-Löschung
Hintergrund

Ein Partikel-System besteht aus: Emitter (erzeugt Partikel nach Zeitplan), Partikel-Liste (verwaltet alle lebenden Partikel), Update-Schritt (Physik + Lebensdauer), Render-Schritt (mit Alpha-Fade). Jedes Partikel hat: Position, Geschwindigkeit, Lebensdauer (lifetime), Maximale Lebensdauer (max_life), Farbe, Größe. Normalized lifetime: t = life/max_life (0.0 = gerade geboren, 1.0 = tot).

Effiziente Löschung: particles[:] = [p for p in particles if p.alive] oder rückwärts per Index. Kraftfelder: Gravitationszentrum: F = k/dist² * normalize(center-pos). Wind: F = const_vector. Explosion: F = normalize(pos-center) * explosion_strength / max(dist, 1). pygame.gfxdraw.filled_circle für Alpha-Partikel oder Surface.set_alpha(). Für sehr viele Partikel (10.000+): numpy-Arrays statt Objekt-Liste.

Schlüsselkonzepte

Partikel-System mit Kraftfeldern

Code anzeigen
import pygame, random, math
pygame.init()
W, H = 800, 600
screen = pygame.display.set_mode((W, H))
clock  = pygame.time.Clock()
font   = pygame.font.SysFont("Arial", 14)

class Particle:
    __slots__ = ["pos","vel","life","max_life","col","size"]
    def __init__(self, x, y, vx, vy, life, col, size=4):
        self.pos      = pygame.math.Vector2(x, y)
        self.vel      = pygame.math.Vector2(vx, vy)
        self.life     = life
        self.max_life = life
        self.col      = col
        self.size     = size

    @property
    def alive(self): return self.life > 0

    @property
    def t(self): return 1.0 - self.life / self.max_life  # 0=jung, 1=tot

particles = []
GRAVITY   = pygame.math.Vector2(0, 120)
WIND      = pygame.math.Vector2(0, 0)
emit_pos  = pygame.math.Vector2(W//2, H//2)
emit_mode = "fountain"   # fountain | smoke | explosion
spawn_acc = 0.0

def spawn(n=1, mode="fountain"):
    for _ in range(n):
        if mode == "fountain":
            a = math.pi * random.uniform(0.2, 0.8)  # Aufwärtskegel
            sp = random.uniform(200, 450)
            col = (random.randint(100,255), random.randint(150,255), random.randint(50,200))
            particles.append(Particle(emit_pos.x, emit_pos.y, math.cos(a)*sp, -math.sin(a)*sp, random.uniform(1.5,3), col, random.randint(3,8)))
        elif mode == "smoke":
            particles.append(Particle(emit_pos.x+random.uniform(-10,10), emit_pos.y, random.uniform(-20,20), random.uniform(-60,-20), random.uniform(2,5), (125,133,144), random.randint(6,18)))
        elif mode == "explosion":
            a  = random.uniform(0, 2*math.pi)
            sp = random.uniform(50, 500)
            col = [(255,100,30),(255,200,30),(255,60,30)][random.randint(0,2)]
            particles.append(Particle(emit_pos.x, emit_pos.y, math.cos(a)*sp, math.sin(a)*sp, random.uniform(0.3,1.2), col, random.randint(2,8)))

running = True
while running:
    dt = min(clock.tick(60)/1000, 0.033)
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.MOUSEMOTION: emit_pos.xy = event.pos
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_1: emit_mode = "fountain"
            if event.key == pygame.K_2: emit_mode = "smoke"
            if event.key == pygame.K_3: emit_mode = "explosion"; spawn(80, "explosion")
            if event.key == pygame.K_w: WIND.x = -150
            if event.key == pygame.K_e: WIND.x =  150
            if event.key == pygame.K_r: WIND.x =  0

    # Spawn
    if emit_mode != "explosion":
        spawn_acc += dt * 40
        n = int(spawn_acc); spawn_acc -= n
        spawn(n, emit_mode)

    # Update
    for p in particles:
        p.vel += (GRAVITY + WIND) * dt
        p.vel *= (1 - 0.5 * dt)  # leichter Drag
        p.pos += p.vel * dt
        p.life -= dt

    particles[:] = [p for p in particles if p.alive and 0 < p.pos.x < W and 0 < p.pos.y < H+50]

    screen.fill((13,17,23))
    for p in particles:
        alpha = int(255 * (1 - p.t))  # Fade-Out
        size  = max(1, int(p.size * (1 - p.t * 0.5)))
        col   = (*p.col, alpha)
        surf  = pygame.Surface((size*2, size*2), pygame.SRCALPHA)
        pygame.draw.circle(surf, col, (size, size), size)
        screen.blit(surf, (int(p.pos.x)-size, int(p.pos.y)-size))

    screen.blit(font.render(f"[1]=Brunnen [2]=Rauch [3]=Explosion  [W/E]=Wind [R]=kein Wind  Partikel:{len(particles)}", True,(125,133,144)),(10,10))
    pygame.display.flip()

pygame.quit()

__slots__ reduziert den Speicherbedarf pro Partikel deutlich — bei 5000 Partikeln macht das einen spürbaren Unterschied.

Aufgabe

Baue ein Partikel-System mit 3 Modi: Brunnen, Rauch, Explosion. Maus kontrolliert Emitter-Position. Wind-Kraft per Tastatur. Alpha-Fade der Partikel implementieren.

Anforderungen
  1. Partikel-Klasse mit life, max_life, t-Property
  2. Spawn-Rate mit Accumulator (kein skip bei niedrigem FPS)
  3. Gravity + Wind als addierbare Kräfte
  4. Alpha-Fade: 255 * (1 - t)
  5. Tote Partikel effizient entfernen: list comprehension
Akzeptanzkriterien
  • Partikel blenden sanft aus
  • Explosion streut radial nach außen
  • System stabil bei 2000+ simultanen Partikeln
