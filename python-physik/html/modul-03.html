Schwerkraft, Bounce & Elastizität

Cheat Sheets
python
Lernziele
  • Bodenkollision mit Restitutionskoeffizient implementieren
  • Wandkollisionen für alle vier Seiten korrekt auflösen
  • Elastizität: e=1 (perfekt elastisch) bis e=0 (perfekt plastisch) verstehen
  • Mehrere Bälle mit unterschiedlicher Elastizität gleichzeitig simulieren
Hintergrund

Restitutionskoeffizient e beschreibt wie viel Energie bei einer Kollision erhalten bleibt: e=1 — Ball springt gleich hoch zurück (Superball). e=0 — Ball bleibt liegen (Knetgummi). e=0.7 — typischer Gummiball. Bei Bodenkollision: wenn ball.pos.y + radius >= BODEN und vel.y > 0, dann vel.y *= -e. Das Vorzeichen wechselt (Richtung umgekehrt), der Betrag wird mit e skaliert.

Wandkollision: ähnlich. Links/Rechts: vel.x *= -e wenn Ball die Wand berührt. Kleines Detail: die Position muss korrigiert werden, damit der Ball nicht in der Wand steckt (Penetrationskorrektur). Dämpfung durch Reibung beim Aufprall: vel.x *= friction_on_bounce (0.98–0.80). Für realistisches Verhalten stoppt der Ball wenn vel.y < threshold — sonst bounced er ewig mit immer kleiner werdenden Hüpfern.

Schlüsselkonzepte

Bouncing Ball mit Restitution

Code anzeigen
import pygame, random
pygame.init()
W, H = 800, 600
screen = pygame.display.set_mode((W, H))
clock  = pygame.time.Clock()
font   = pygame.font.SysFont("Arial", 14)

GRAVITY = 600  # px/s²
PALETTE = [(63,185,80),(88,166,255),(255,123,114),(255,166,87),(64,209,172)]

class Ball:
    def __init__(self):
        self.r   = random.randint(10, 25)
        self.pos = pygame.math.Vector2(random.randint(self.r, W-self.r), random.randint(50, 200))
        self.vel = pygame.math.Vector2(random.uniform(-200,200), 0)
        self.e   = round(random.uniform(0.4, 0.95), 2)  # Elastizität
        self.col = random.choice(PALETTE)

    def update(self, dt):
        self.vel.y += GRAVITY * dt
        self.pos   += self.vel * dt

        # Boden
        if self.pos.y + self.r >= H:
            self.pos.y = H - self.r
            if abs(self.vel.y) > 5:
                self.vel.y *= -self.e
                self.vel.x *= 0.95   # Reibung beim Aufprall
            else:
                self.vel.y = 0

        # Decke
        if self.pos.y - self.r <= 0:
            self.pos.y = self.r
            self.vel.y *= -self.e

        # Wände
        if self.pos.x - self.r <= 0:
            self.pos.x = self.r
            self.vel.x = abs(self.vel.x) * self.e
        if self.pos.x + self.r >= W:
            self.pos.x = W - self.r
            self.vel.x = -abs(self.vel.x) * self.e

    def draw(self, surf):
        pygame.draw.circle(surf, self.col,  (int(self.pos.x), int(self.pos.y)), self.r)
        pygame.draw.circle(surf, (255,255,255), (int(self.pos.x), int(self.pos.y)), self.r, 1)
        lbl = font.render(f"e={self.e}", True, (230,237,243))
        surf.blit(lbl, (int(self.pos.x)-15, int(self.pos.y)-self.r-16))

balls = [Ball() for _ in range(8)]
running = True
while running:
    dt = min(clock.tick(60)/1000, 0.05)  # dt clampen: verhindert Tunnel-Bug bei Lag
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            balls.append(Ball())

    for b in balls: b.update(dt)

    screen.fill((13, 17, 23))
    for b in balls: b.draw(screen)
    screen.blit(font.render(f"Klick = neuer Ball  |  Bälle: {len(balls)}", True, (125,133,144)), (10,10))
    pygame.display.flip()

pygame.quit()

dt = min(..., 0.05) ist wichtig: bei Lags würde ein großer dt-Wert Bälle durch Wände tunneln lassen.

Aufgabe

Baue eine Simulation mit 10+ Bällen verschiedener Größen und Elastizitäten, die innerhalb eines Rechtecks bouncing sind. Elastizitäts-Wert wird über dem Ball angezeigt. Klick fügt neuen Ball hinzu.

Anforderungen
  1. Restitutionskoeffizient e für jeden Ball individuell
  2. Bodenkollision mit Penetrationskorrektur (pos anpassen)
  3. Alle 4 Wände korrekt
  4. Reibung beim Bodenaufprall (vel.x *= 0.95)
  5. dt auf 0.05 geclampt gegen Tunnel-Bug
Akzeptanzkriterien
  • Bälle bouncing realistisch und verlassen nie den Bereich
  • Hochelastische Bälle springen höher als niedrige
  • Simulation stabil bei 60+ Bällen
