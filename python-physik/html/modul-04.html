Reibung & Luftwiderstand

Cheat Sheets
python
Lernziele
  • Coulomb-Reibung (Gleitreibung) auf Oberflächen simulieren
  • Luftwiderstand (Stokes-Drag) als geschwindigkeitsabhängige Kraft implementieren
  • Den Unterschied zwischen linearem und quadratischem Drag verstehen
  • Energieerhaltung durch Debug-Anzeige (kinetische + potentielle Energie) visualisieren
Hintergrund

Reibungskraft nach Coulomb: F_reibung = μ * F_normal (μ = Reibungskoeffizient, F_normal = Normalkraft). Für einen Ball auf dem Boden: F_normal = m*g, daher F_reibung = μ*m*g. Beschleunigung durch Reibung: a_reibung = μ*g, in Richtung der negativen Horizontalgeschwindigkeit. In der Simulation: vel.x -= sign(vel.x) * mu * g * dt.

Luftwiderstand: Stokes-Drag (niedrige Geschwindigkeit, kleine Objekte): F_drag = -k * v. Implementierung: vel *= (1 - k * dt). Newton-Drag (hohe Geschwindigkeit, große Objekte): F_drag = -0.5 * rho * Cd * A * v². Für Spielsimulationen reicht linearer Drag. Energiebetrachtung: E_kin = 0.5*m*v² (kinetisch), E_pot = m*g*h (potentiell). Ohne Dämpfung sollte E_total konstant bleiben.

Code anzeigen
import pygame, math
pygame.init()
W, H = 800, 600
screen = pygame.display.set_mode((W, H))
clock  = pygame.time.Clock()
font   = pygame.font.SysFont("Arial", 14)

GRAVITY = 600.0
MU      = 0.3    # Coulomb-Reibungskoeffizient
DRAG    = 0.8    # Luftwiderstand-Koeffizient (linear)
MASS    = 1.0

class Ball:
    def __init__(self, x, y, vx, vy):
        self.pos  = pygame.math.Vector2(x, y)
        self.vel  = pygame.math.Vector2(vx, vy)
        self.r    = 18
        self.on_ground = False

    def update(self, dt):
        # Schwerkraft
        self.vel.y += GRAVITY * dt

        # Luftwiderstand (immer aktiv)
        self.vel *= max(0, 1 - DRAG * dt)

        # Boden-Kollision
        if self.pos.y + self.r >= H - 60:
            self.pos.y = H - 60 - self.r
            self.vel.y *= -0.7  # Restitution
            self.on_ground = True

            # Coulomb-Reibung (nur am Boden)
            friction_decel = MU * GRAVITY  # μ*g
            if abs(self.vel.x) > friction_decel * dt:
                self.vel.x -= math.copysign(friction_decel * dt, self.vel.x)
            else:
                self.vel.x = 0
        else:
            self.on_ground = False

        self.pos += self.vel * dt

        # Wände
        for edge, sign in [(self.r, 1), (W - self.r, -1)]:
            if (sign == 1 and self.pos.x < edge) or (sign == -1 and self.pos.x > edge):
                self.pos.x = edge
                self.vel.x *= -0.8

    def energy(self, height_ref):
        h   = max(0, height_ref - self.pos.y)
        ek  = 0.5 * MASS * self.vel.length_squared()
        ep  = MASS * GRAVITY * h / 1000  # normiert
        return ek, ep

    def draw(self, surf):
        pygame.draw.circle(surf, (88,166,255), (int(self.pos.x),int(self.pos.y)), self.r)
        ek, ep = self.energy(H-60)
        bar_x = int(self.pos.x) - 20
        pygame.draw.rect(surf, (63,185,80),   (bar_x, int(self.pos.y)-self.r-20, min(40,int(ek/100)), 4))
        pygame.draw.rect(surf, (255,166,87),  (bar_x, int(self.pos.y)-self.r-14, min(40,int(ep/100)), 4))

ball = Ball(200, 100, 300, -200)
running = True
while running:
    dt = min(clock.tick(60)/1000, 0.05)
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            ball = Ball(event.pos[0], event.pos[1]-30, 300, -300)

    ball.update(dt)
    ek, ep = ball.energy(H-60)

    screen.fill((13, 17, 23))
    pygame.draw.rect(screen, (30,40,30), (0, H-60, W, 60))  # Boden
    ball.draw(screen)
    screen.blit(font.render(f"μ={MU} (Reibung)  Drag={DRAG}  E_kin={ek:.0f}  E_pot={ep:.0f}  Σ={ek+ep:.0f}", True, (125,133,144)), (10,10))
    screen.blit(font.render("Grün=E_kin  Orange=E_pot  (Balken über Ball)", True, (125,133,144)), (10,28))
    pygame.display.flip()

pygame.quit()
Aufgabe

Implementiere eine Simulation mit einstellbarem μ (Reibung) und Drag-Koeffizient. Zeige kinetische und potentielle Energie als Balken über dem Ball. Beobachte wie Energie dissipiert.

Anforderungen
  1. Coulomb-Reibung: nur am Boden, richtungsabhängig mit copysign
  2. Drag: vel *= (1 - drag * dt)
  3. Reibung und Drag unabhängig einstellbar
  4. Energieanzeige: E_kin und E_pot separat
  5. Gesamtenergie nimmt mit Zeit ab (Dämpfung sichtbar)
Akzeptanzkriterien
  • Ball kommt durch Reibung zum Stillstand
  • Luftwiderstand verlangsamt auch freien Fall
  • Energieanzeige zeigt plausible Werte
