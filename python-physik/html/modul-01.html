Vektoren & pygame.math.Vector2

Cheat Sheets
python
Lernziele
  • pygame.math.Vector2 für 2D-Physik einsetzen
  • Vektoroperationen: Addition, Skalierung, Länge, Normalisierung
  • Dot-Product und seine physikalische Bedeutung verstehen
  • Reflexionsvektor über das Dot-Product berechnen
Hintergrund

In der Physik-Simulation ist fast alles ein Vektor: Position, Geschwindigkeit, Beschleunigung, Kraft. pygame.math.Vector2 bietet alle nötigen Operationen nativ. v.length() gibt den Betrag, v.normalize() einen Einheitsvektor (Länge 1), v.dot(w) das Skalarprodukt. Das Skalarprodukt a·b = |a||b|·cos(θ) — wenn es negativ ist, zeigen die Vektoren in entgegengesetzte Richtungen.

Reflexion eines Vektors v an einer Normalen n: r = v - 2·(v·n)·n. Diese Formel taucht in jeder Kollisionsauflösung auf. pygame.math.Vector2.reflect(normal) berechnet das direkt. Wichtig: die Normale muss normalisiert sein (Länge 1), sonst ist das Ergebnis falsch.

Schlüsselkonzepte

Vector2 Grundoperationen

Code anzeigen
import pygame
pygame.init()

# Vektoren erstellen
a = pygame.math.Vector2(3, 4)
b = pygame.math.Vector2(1, -2)

# Grundoperationen
print(a + b)             # (4, 2)
print(a - b)             # (2, 6)
print(a * 2)             # (6, 8)
print(a.length())        # 5.0   (Betrag: sqrt(3²+4²))
print(a.normalize())     # (0.6, 0.8)

# Skalarprodukt
dot = a.dot(b)           # 3*1 + 4*(-2) = -5
print(dot)               # -5  → Vektoren zeigen "weg voneinander"

# Winkel zwischen Vektoren
import math
cos_angle = a.dot(b) / (a.length() * b.length())
angle_deg = math.degrees(math.acos(max(-1, min(1, cos_angle))))
print(f"Winkel: {angle_deg:.1f}°")

# Reflexion an einer horizontalen Fläche
velocity = pygame.math.Vector2(2, 3)   # Ball fliegt nach unten-rechts
normal   = pygame.math.Vector2(0, -1)  # Normale zeigt nach oben
reflected = velocity.reflect(normal)
print(reflected)  # (2, -3) — Y-Komponente gespiegelt

Vektoren visualisieren

Code anzeigen
import pygame, math
pygame.init()
screen = pygame.display.set_mode((700, 500))
clock  = pygame.time.Clock()

def draw_arrow(surf, color, start, end, width=2):
    pygame.draw.line(surf, color, start, end, width)
    # Pfeilspitze
    v = pygame.math.Vector2(end) - pygame.math.Vector2(start)
    if v.length() < 1: return
    v_n = v.normalize()
    perp = pygame.math.Vector2(-v_n.y, v_n.x)
    tip = pygame.math.Vector2(end)
    p1 = tip - v_n * 12 + perp * 5
    p2 = tip - v_n * 12 - perp * 5
    pygame.draw.polygon(surf, color, [end, p1, p2])

running = True
while running:
    clock.tick(60)
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False

    mx, my = pygame.mouse.get_pos()
    origin = pygame.math.Vector2(350, 250)
    mouse_v = pygame.math.Vector2(mx, my) - origin
    normal  = pygame.math.Vector2(0, -1)

    screen.fill((13, 17, 23))
    pygame.draw.line(screen, (48,54,61), (0,250), (700,250), 1)  # Boden

    if mouse_v.length() > 1:
        reflected = mouse_v.reflect(normal)
        draw_arrow(screen, (63,185,80),   origin, origin + mouse_v,   2)
        draw_arrow(screen, (255,123,114), origin, origin + reflected, 2)
        dot = mouse_v.normalize().dot(normal)
        font = pygame.font.SysFont("Arial", 16)
        screen.blit(font.render(f"v·n = {dot:.2f}", True, (125,133,144)), (20,20))
    pygame.display.flip()

pygame.quit()

Interaktiv: Maus bewegen zeigt Einfall- und Reflexionsvektor in Echtzeit.

Aufgabe

Erstelle eine interaktive Visualisierung, die für einen Maus-Vektor dessen Länge, Normalisierung, Dot-Product mit einer festen Achse und den Reflexionsvektor anzeigt.
