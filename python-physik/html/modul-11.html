Verlet-Integration & Constraints

Cheat Sheets
python
Lernziele
  • Positionsbasierte Verlet-Integration implementieren
  • Stick-Constraints (Starre Abstands-Verbindungen) iterativ lösen
  • Ein Seil (Rope) aus Constraints bauen
  • Ein einfaches Tuch-Gitter (Cloth) mit Constraint-Solver simulieren
Hintergrund

Verlet-Integration ist numerisch stabiler als Euler für Constraint-Systeme. Statt Geschwindigkeit speichern wir nur die aktuelle und vorherige Position. Geschwindigkeit ist implizit: v ≈ (pos - pos_old) / dt. Update: pos_new = 2*pos - pos_old + acc*dt². pos_old = pos; pos = pos_new. Der große Vorteil: Constraints (Abstands-Bedingungen) können direkt auf Positionen angewandt werden, ohne die Geschwindigkeit manuell zu korrigieren.

Stick-Constraint: Zwei Punkte A, B sollen immer Abstand L haben. Delta = B-A. dist = |Delta|. Fehler = (dist-L)/dist. A += Delta * 0.5 * Fehler; B -= Delta * 0.5 * Fehler. Iteratives Auflösen (5–20 Iterationen): je mehr, desto steifer. Seil: Kette von Punkten mit Stick-Constraints. Tuch: 2D-Gitter mit horizontalen, vertikalen und diagonalen Constraints.

Verlet + Cloth-Simulation

Code anzeigen
import pygame, random
pygame.init()
W, H = 800, 600
screen = pygame.display.set_mode((W, H))
clock  = pygame.time.Clock()
font   = pygame.font.SysFont("Arial", 14)

COLS, ROWS  = 18, 14
SPACING     = 36
ITERATIONS  = 8
START_X     = (W - COLS*SPACING)//2
START_Y     = 60
GRAVITY_Y   = 500

class Point:
    def __init__(self, x, y, pinned=False):
        self.pos     = pygame.math.Vector2(x, y)
        self.old_pos = pygame.math.Vector2(x, y)
        self.pinned  = pinned

    def update(self, dt):
        if self.pinned: return
        vel       = (self.pos - self.old_pos) * 0.99  # Dämpfung
        self.old_pos = pygame.math.Vector2(self.pos)
        self.pos += vel + pygame.math.Vector2(0, GRAVITY_Y) * dt * dt
        # Grenzen
        if self.pos.y > H-5: self.pos.y = H-5
        if self.pos.x < 5:   self.pos.x = 5
        if self.pos.x > W-5: self.pos.x = W-5

class Stick:
    def __init__(self, a, b):
        self.a    = a
        self.b    = b
        self.rest = (b.pos - a.pos).length()
        self.active = True

    def solve(self):
        if not self.active: return
        delta = self.b.pos - self.a.pos
        dist  = delta.length()
        if dist < 0.001: return
        diff  = (dist - self.rest) / dist
        if not self.a.pinned: self.a.pos += delta * 0.5 * diff
        if not self.b.pinned: self.b.pos -= delta * 0.5 * diff

# Tuch aufbauen
points = []
for row in range(ROWS):
    for col in range(COLS):
        pinned = (row == 0 and col % 3 == 0)
        points.append(Point(START_X + col*SPACING, START_Y + row*SPACING, pinned))

sticks = []
for row in range(ROWS):
    for col in range(COLS):
        idx = row*COLS + col
        if col < COLS-1: sticks.append(Stick(points[idx], points[idx+1]))
        if row < ROWS-1: sticks.append(Stick(points[idx], points[idx+COLS]))

drag_point = None
running = True
while running:
    dt = min(clock.tick(60)/1000, 0.033)
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            mx, my = event.pos
            best = min(points, key=lambda p: (p.pos.x-mx)**2+(p.pos.y-my)**2)
            if event.button == 1: drag_point = best
            if event.button == 3:  # Rechtsklick: Sticks in Nähe zerschneiden
                for s in sticks:
                    c = (s.a.pos + s.b.pos) / 2
                    if (c - pygame.math.Vector2(mx,my)).length() < 20: s.active = False
        if event.type == pygame.MOUSEBUTTONUP: drag_point = None
        if event.type == pygame.MOUSEMOTION and drag_point:
            drag_point.pos.xy = event.pos
            drag_point.old_pos.xy = event.pos

    for p in points: p.update(dt)
    for _ in range(ITERATIONS):
        for s in sticks: s.solve()

    screen.fill((13,17,23))
    for s in sticks:
        if not s.active: continue
        col = (63,185,80) if s.a.pos.y < 100 else (88,166,255)
        pygame.draw.line(screen, col, (int(s.a.pos.x),int(s.a.pos.y)),(int(s.b.pos.x),int(s.b.pos.y)),1)
    for p in points:
        col = (255,255,255) if p.pinned else (125,133,144)
        pygame.draw.circle(screen, col, (int(p.pos.x),int(p.pos.y)), 3 if p.pinned else 2)
    screen.blit(font.render("Ziehen=Linksklick  Tuch zerschneiden=Rechtsklick", True,(125,133,144)),(10,10))
    pygame.display.flip()

pygame.quit()

ITERATIONS=8 reicht für weiches Tuch. Für ein Seil mit kaum Elastizität: 20+ Iterationen.

Aufgabe

Baue eine interaktive Tuch-Simulation (mind. 12×10 Punkte). Linksklick zieht, Rechtsklick zerschneidet. Obere Reihe oben fixiert (jeder 3. Punkt).

Anforderungen
  1. Verlet-Update: pos_new = 2*pos - pos_old + g*dt²
  2. old_pos = pos vor dem Update
  3. Stick-Constraint: diff = (dist-rest)/dist
  4. Iterativer Solver: 8+ Iterationen
  5. Pinned-Punkte werden nicht bewegt
  6. Zerschneiden: Stick.active = False
Akzeptanzkriterien
  • Tuch hängt realistisch durch Gravitation
  • Zerschneiden hinterlässt sichtbare Lücken
  • Ziehen zieht das Tuch mit
