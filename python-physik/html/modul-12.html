Physik-Sandbox: Interaktiv

Cheat Sheets
python
Lernziele
  • Alle Physik-Module in eine interaktive Sandbox integrieren
  • Ein Werkzeug-System (Spawn, Bewegen, Kräfte, Löschen) implementieren
  • Preset-Szenarien laden (Billard, Kegeln, Pendel, Parcours)
  • Simulation pausieren, zeitlupen und Screenshot exportieren
Hintergrund

Eine Physik-Sandbox kombiniert alles: Bälle mit Masse und Elastizität, Linienhindernisse, Gravitationsfelder, Federsysteme. Der Schlüssel ist ein gutes Werkzeug-System: aktuelles Werkzeug bestimmt was ein Mausklick tut (Ball spawnen, Linie zeichnen, Kraft ausüben, Objekt löschen). Tastatur wechselt zwischen Werkzeugen.

Preset-System: Eine Funktion pro Szenario, die Bälle und Hindernisse platziert. Zeitlupe: dt *= 0.2. Pause: dt = 0. Screenshot: pygame.image.save(screen, "screenshot.png"). Render-Qualitäten: Anti-aliasing mit pygame.draw.aacircle (wo verfügbar) oder gfxdraw. Statistik-Overlay: Anzahl Objekte, Kollisionen/Frame, FPS, Gesamtenergie.

# Empfohlene Struktur für die Physik-Sandbox:

import pygame
from enum import Enum, auto

class Tool(Enum):
    SPAWN_BALL  = auto()
    DRAW_LINE   = auto()
    APPLY_FORCE = auto()
    DELETE      = auto()

class PhysicsSandbox:
    def __init__(self):
        self.balls     = []
        self.lines     = []
        self.tool      = Tool.SPAWN_BALL
        self.paused    = False
        self.timescale = 1.0
        self.grid      = {}           # Spatial Grid
        self.frame     = 0
        self.line_start = None        # für Line-Drawing

    def handle_event(self, event):
        if event.type == pygame.KEYDOWN:
            keys = {pygame.K_1: Tool.SPAWN_BALL, pygame.K_2: Tool.DRAW_LINE,
                    pygame.K_3: Tool.APPLY_FORCE, pygame.K_4: Tool.DELETE}
            if event.key in keys: self.tool = keys[event.key]
            if event.key == pygame.K_SPACE: self.paused = not self.paused
            if event.key == pygame.K_t:     self.timescale = 0.1 if self.timescale==1 else 1.0
            if event.key == pygame.K_s:     pygame.image.save(pygame.display.get_surface(), f"sandbox_{self.frame}.png")
            if event.key == pygame.K_c:     self.balls.clear(); self.lines.clear()

    def update(self, dt):
        if self.paused: return
        dt *= self.timescale
        # Spatial Grid aufbauen
        self.grid = {}
        for b in self.balls:
            key = (int(b.pos.x // 60), int(b.pos.y // 60))
            self.grid.setdefault(key, []).append(b)
        # Physik...
        self.frame += 1

    def draw_hud(self, surf, font):
        status = "PAUSE" if self.paused else f"{self.timescale:.1f}x"
        lines  = [
            f"Werkzeug: {self.tool.name}  ({status})",
            f"Bälle: {len(self.balls)}  Linien: {len(self.lines)}",
            f"[1-4]=Werkzeuge  [SPACE]=Pause  [T]=Zeitlupe  [S]=Screenshot  [C]=Löschen",
        ]
        for i, l in enumerate(lines):
            surf.blit(font.render(l, True, (125,133,144)), (10, 10+i*18))

def preset_billard(sandbox):
    """8 Bälle in Dreieck-Formation."""
    sandbox.balls.clear()
    cx, cy = 550, 300
    r = 18
    row_offsets = [0, 1, 2, 3]
    for row in row_offsets:
        for col in range(row+1):
            x = cx + row * (r*2+2)
            y = cy + col*(r*2+2) - row*(r+1)
            sandbox.balls.append(Ball(x, y, 0, 0, mass=1))
    # Cue-Ball
    sandbox.balls.append(Ball(200, 300, 350, 0, mass=1.2))

def preset_parcours(sandbox):
    """Ball durch Hindernisparcours."""
    sandbox.balls.clear()
    sandbox.lines.clear()
    sandbox.balls.append(Ball(100, 50, 200, 0, mass=1))
    sandbox.lines = [
        ((50,200),(350,300)),
        ((350,300),(650,150)),
        ((200,400),(600,420)),
    ]

# Presets registrieren
PRESETS = {
    pygame.K_F1: ("Billard",   preset_billard),
    pygame.K_F2: ("Parcours",  preset_parcours),
}

Presets lassen sich schnell testen ohne neu zu starten — wichtig für das Debugging der Physik-Systeme.

Aufgabe

Baue die vollständige Physik-Sandbox mit 4 Werkzeugen, 2 Presets, Pause, Zeitlupe und Screenshot. Integriere Kreis-Kreis-Kollision mit Spatial Grid und Kreis-Linie-Kollision.

Anforderungen
  1. PhysicsSandbox-Klasse mit balls, lines, tool, paused, timescale
  2. 4 Werkzeuge: SPAWN_BALL, DRAW_LINE, APPLY_FORCE, DELETE
  3. Spatial Grid für Kreis-Kreis-Broadphase integriert
  4. Kreis-Linie-Kollision korrekt (Lotfußpunkt-Methode)
  5. Pause: dt=0, Zeitlupe: dt*=0.1
  6. Screenshot: pygame.image.save()
  7. Preset F1: Billard-Setup Preset F2: Parcours
Akzeptanzkriterien
  • Alle 4 Werkzeuge funktionieren korrekt
  • Kollisionen mit Linien und Bällen stabil
  • Screenshot wird korrekt gespeichert
  • Preset-Szenarien starten fehlerfrei
