Gegner-KI

Cheat Sheets
python
Lernziele
  • Eine einfache State Machine für Gegner-Verhalten implementieren
  • Patrol- und Chase-Verhalten mit Sichtweite umsetzen
  • Gegner-Angriff mit Cooldown implementieren
  • Mehrere Gegner-Typen durch Klassen-Vererbung erstellen
Hintergrund

Gegner-KI in einfachen Spielen basiert auf State Machines: der Gegner wechselt zwischen Zuständen (PATROL, CHASE, ATTACK, STUN) abhängig von Spieler-Nähe und anderen Bedingungen. PATROL: der Gegner bewegt sich zwischen zwei Punkten hin und her. CHASE: sobald der Spieler in Sichtweite ist (Distanz < sight_range), verfolgt der Gegner. ATTACK: sobald der Spieler in Reichweite ist (Distanz < attack_range), greift der Gegner an.

Distanzberechnung: math.hypot(dx, dy) oder pygame.math.Vector2.distance_to(). Richtungsvektor zum Spieler normalisiert: v = target - pos; v.normalize_ip(). Cooldown-System: attack_cooldown startet bei attack_rate, wird jeden Frame um dt verringert, der Angriff ist möglich wenn cooldown <= 0. Nach dem Angriff wird cooldown = attack_rate zurückgesetzt. Vererbung: class FlyingEnemy(Enemy) überschreibt nur was sich ändert.

Gegner-State-Machine

Code anzeigen
import pygame, sys, math, random

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock  = pygame.time.Clock()

PATROL, CHASE, ATTACK, STUN = "patrol","chase","attack","stun"

class Enemy(pygame.sprite.Sprite):
    SIGHT   = 250   # px
    ATTACK  = 60    # px
    SPEED   = 120   # px/s
    ATK_CD  = 1.5   # Sekunden

    def __init__(self, x, y, patrol_end):
        super().__init__()
        self.image = pygame.Surface((36, 36), pygame.SRCALPHA)
        pygame.draw.circle(self.image, (255,123,114), (18,18), 18)
        self.rect         = self.image.get_rect(center=(x, y))
        self.patrol_start = x
        self.patrol_end   = patrol_end
        self.state        = PATROL
        self.dir          = 1
        self.atk_cd       = 0
        self.stun_timer   = 0

    def update(self, dt, player_rect):
        px, py = player_rect.center
        ex, ey = self.rect.center
        dist   = math.hypot(px - ex, py - ey)

        # Zustandswechsel
        if self.state == STUN:
            self.stun_timer -= dt
            if self.stun_timer <= 0: self.state = PATROL
            return

        if dist < self.ATTACK:
            self.state = ATTACK
        elif dist < self.SIGHT:
            self.state = CHASE
        else:
            self.state = PATROL

        if self.state == PATROL:
            self.rect.x += int(self.dir * self.SPEED * dt)
            if self.rect.x >= self.patrol_end or self.rect.x <= self.patrol_start:
                self.dir *= -1

        elif self.state == CHASE:
            dx, dy = px - ex, py - ey
            length = math.hypot(dx, dy) or 1
            self.rect.x += int((dx/length) * self.SPEED * dt)
            self.rect.y += int((dy/length) * self.SPEED * dt)

        elif self.state == ATTACK:
            self.atk_cd -= dt
            if self.atk_cd <= 0:
                self.atk_cd = self.ATK_CD
                print("Angriff!")   # hier: Schaden an Spieler

    def stun(self, duration=1.0):
        self.state      = STUN
        self.stun_timer = duration

    def draw_debug(self, surface):
        col = {PATROL:(125,133,144),CHASE:(255,166,87),ATTACK:(255,123,114),STUN:(88,166,255)}.get(self.state)
        pygame.draw.circle(surface, col, self.rect.center, self.SIGHT, 1)
        pygame.draw.circle(surface, col, self.rect.center, self.ATTACK, 1)

player_rect = pygame.Rect(370, 270, 36, 48)
enemies = pygame.sprite.Group()
enemies.add(Enemy(100, 300, 350))
enemies.add(Enemy(500, 400, 750))

running = True
while running:
    dt = clock.tick(60) / 1000
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
            for e in enemies: e.stun(2.0)

    keys = pygame.key.get_pressed()
    dx = (-3 if keys[pygame.K_a] else 3 if keys[pygame.K_d] else 0)
    dy = (-3 if keys[pygame.K_w] else 3 if keys[pygame.K_s] else 0)
    player_rect.move_ip(dx, dy)

    for e in enemies: e.update(dt, player_rect)

    screen.fill((13, 17, 23))
    for e in enemies: e.draw_debug(screen)
    enemies.draw(screen)
    pygame.draw.rect(screen, (88,166,255), player_rect)
    pygame.display.flip()

pygame.quit(); sys.exit()

Debug-Kreise für SIGHT und ATTACK visualisieren die KI-Radiusse — im fertigen Spiel einfach draw_debug() entfernen.

Aufgabe

Implementiere zwei Gegner-Typen (Boden-Patrol und Fernkämpfer) mit State Machine. Beide sollen den Spieler verfolgen sobald er in Sichtweite ist, mit unterschiedlichen Angriffs-Reichweiten.

Anforderungen
  1. Enemy-Basisklasse mit State Machine: PATROL/CHASE/ATTACK/STUN
  2. Distanzberechnung mit math.hypot() korrekt
  3. Patrol: Hin- und Herbewegung zwischen zwei Punkten
  4. Chase: normalisierter Richtungsvektor zum Spieler
  5. Attack-Cooldown mit Timer implementiert
  6. Zweiter Gegner-Typ erbt von Enemy und überschreibt Konstanten
Akzeptanzkriterien
  • Gegner wechseln Zustände korrekt bei Distanzänderung
  • STUN-Zustand verhindert Aktion für angegebene Dauer
  • Beide Gegner-Typen verhalten sich unterschiedlich
