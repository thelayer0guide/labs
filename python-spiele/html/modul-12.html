Abschlussprojekt: Vollständiges Spiel

Cheat Sheets
python
Lernziele
  • Alle gelernten Konzepte zu einem vollständigen Spiel integrieren
  • Code refaktorieren: Klassen, Module, saubere Architektur
  • Das Spiel mit PyInstaller in eine ausführbare Datei verpacken
  • Performance-Engpässe mit dem pygame Profiler identifizieren
Hintergrund

Ein vollständiges Spiel verbindet alle Module: Game Loop (01), Grafik (02), Eingabe (03), Bewegung/Kollision (04), Sprites/Animation (05), Sound (06), Mechaniken (07), UI/Menüs (08), Tilemap/Kamera (09), Gegner-KI (10), Speichersystem (11). Refactoring-Schritte: jedes System in eine eigene Python-Datei auslagern (player.py, enemy.py, ui.py, save.py), eine Game-Klasse als zentralen Koordinator, Konstanten in settings.py.

Distribution: PyInstaller verpackt das Spiel und den Python-Interpreter in eine .exe/.app: pip install pyinstaller; pyinstaller --onefile --windowed main.py. Assets mit --add-data "assets:assets" einschließen. Performance: pygame.display.flip() vs update(rect_list) — update nur veränderte Bereiche. Sprite-Surface mit convert() oder convert_alpha() laden — deutlich schneller. Dirty-Sprites: pygame.sprite.LayeredDirty für Spiele mit vielen statischen Elementen.

Eine klare Ordnerstruktur macht das Projekt wartbar. src/__init__.py erlaubt Import-Aliase.

PyInstaller & Distribution

Code anzeigen
# Installation
pip install pyinstaller

# Einfaches Build (einzelne .exe)
pyinstaller --onefile --windowed --name "MeinSpiel" main.py

# Mit Assets
pyinstaller --onefile --windowed \\
    --add-data "assets:assets" \\
    --icon assets/icon.ico \\
    main.py

# Pfad zu Assets im Code korrekt auflösen:
import sys, os

def resource_path(relative_path):
    """Pfad zu einer Ressource, auch nach PyInstaller-Verpackung."""
    if hasattr(sys, "_MEIPASS"):
        return os.path.join(sys._MEIPASS, relative_path)
    return os.path.join(os.path.dirname(os.path.abspath(__file__)), relative_path)

# Nutzung:
img = pygame.image.load(resource_path("assets/images/player.png"))

sys._MEIPASS ist der temporäre Entpackungsordner von PyInstaller. Ohne resource_path() findet das .exe-Bundle keine Asset-Dateien.

Aufgabe

Baue ein spielbares Spiel mit mindestens: State Machine (Menü/Spielen/Pause/Game-Over), steuerbarem Spieler, 2+ Gegner-Typen, Score-System, Sound, HUD und Speichersystem. Verpacke es mit PyInstaller.

Anforderungen
  1. Saubere Modul-Struktur: src/ mit separaten .py-Dateien pro System
  2. Game-Klasse koordiniert alle Systeme (init, run, update, draw)
  3. State Machine: mind. 4 Zustände vollständig
  4. Spieler, Gegner-KI, Kollision, Sound, HUD, Score — alle integriert
  5. Spielstand wird beim Beenden gespeichert, beim Start geladen
  6. PyInstaller-Build erstellt lauffähige Datei
  7. resource_path()-Funktion für Asset-Pfade
Akzeptanzkriterien
  • Spiel ist spielbar von Start bis Game Over
  • Alle Systeme kooperieren ohne Abstürze
  • PyInstaller-Build läuft auf anderem Rechner ohne Python-Installation
