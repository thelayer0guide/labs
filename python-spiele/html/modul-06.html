Sound & Musik

Cheat Sheets
python
Lernziele
  • pygame.mixer initialisieren und konfigurieren
  • Sound-Effekte laden und kontrolliert abspielen
  • Hintergrundmusik mit pygame.mixer.music steuern
  • Lautstärke, Channels und Fade-Effekte einsetzen
Hintergrund

pygame.mixer verwaltet Audioausgabe. pygame.mixer.init(frequency=44100, size=-16, channels=2, buffer=512) initialisiert es (passiert auch durch pygame.init()). Sound-Effekte: pygame.mixer.Sound("sound.wav") lädt eine WAV/OGG-Datei. sound.play() spielt einmal ab, sound.play(-1) wiederholt endlos. sound.set_volume(0.5) setzt Lautstärke (0.0–1.0).

Hintergrundmusik: pygame.mixer.music.load("musik.ogg"). music.play(-1) für Loop, music.set_volume(0.3), music.pause()/music.unpause(), music.fadeout(2000) blendet in 2 Sekunden aus. Channels: pygame.mixer.Channel(0) gibt direkten Zugriff auf einen Kanal für parallele Sounds. pygame.mixer.find_channel() findet einen freien Kanal. Für Spiele empfehlen sich OGG für Musik und WAV/OGG für Effekte.

Schlüsselkonzepte

Sound-System aufbauen

Code anzeigen
import pygame, sys

pygame.init()
# Mixer vor dem Display initialisieren für geringere Latenz
pygame.mixer.pre_init(44100, -16, 2, 512)
screen = pygame.display.set_mode((800, 600))
clock  = pygame.time.Clock()

# ── Sound-Effekte (aus Bytes generiert, kein File nötig) ──────────────
import numpy as np, array

def beep(freq, dur_ms, vol=0.4):
    """Einfachen Ton synthetisieren."""
    sample_rate = 44100
    n_samples   = int(sample_rate * dur_ms / 1000)
    t = np.linspace(0, dur_ms/1000, n_samples, False)
    wave = (np.sin(2 * np.pi * freq * t) * 32767 * vol).astype(np.int16)
    stereo = np.column_stack([wave, wave])
    sound  = pygame.sndarray.make_sound(stereo)
    return sound

try:
    snd_jump   = beep(440, 80)
    snd_coin   = beep(880, 60)
    snd_hit    = beep(150, 200, 0.6)
except Exception:
    snd_jump = snd_coin = snd_hit = None  # numpy nicht verfügbar

# ── Lautstärke-Steuerung ──────────────────────────────────────────────
master_volume = 0.7

def play_sfx(sound):
    if sound:
        sound.set_volume(master_volume)
        sound.play()

font = pygame.font.SysFont("Arial", 20)
running = True
while running:
    clock.tick(60)
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE: play_sfx(snd_jump)
            if event.key == pygame.K_c:     play_sfx(snd_coin)
            if event.key == pygame.K_h:     play_sfx(snd_hit)
            if event.key == pygame.K_UP:    master_volume = min(1.0, master_volume + 0.1)
            if event.key == pygame.K_DOWN:  master_volume = max(0.0, master_volume - 0.1)

    screen.fill((13, 17, 23))
    txt = font.render(f"SPACE=Sprung  C=Coin  H=Treffer  Lautst.: {master_volume:.1f}", True, (125,133,144))
    screen.blit(txt, (20, 20))
    pygame.display.flip()

pygame.quit(); sys.exit()

Töne können auch per Code synthetisiert werden — gut für Prototyping ohne Asset-Dateien. Für ein echtes Spiel OGG-Dateien verwenden.

Aufgabe

Baue ein Sound-System mit Lautstärke-Kontrolle. Mindestens 3 verschiedene Sound-Effekte sollen auf Tastendruck abspielen. Zeige die aktuelle Lautstärke im HUD an und ermögliche Anpassung per Tastatur.

Anforderungen
  1. pygame.mixer.pre_init() vor pygame.init() gesetzt
  2. 3+ Sound-Effekte mit unterschiedlichem Charakter
  3. Lautstärke-Variable zwischen 0.0 und 1.0 geclampt
  4. Lautstärke-Anzeige im HUD aktuell
  5. Hintergrundmusik: load, play(-1), set_volume, pause/unpause
Akzeptanzkriterien
  • Sound-Effekte spielen ohne Knacken/Latenz ab
  • Lautstärke-Kontrolle funktioniert
  • Programm läuft ohne Audio-Fehler
