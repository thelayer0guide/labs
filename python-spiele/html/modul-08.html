UI, Menüs & HUD

Cheat Sheets
python
Lernziele
  • Ein Hauptmenü mit klickbaren Buttons implementieren
  • Einen Pause-Zustand mit Overlay korrekt umsetzen
  • Ein Game-Over-Screen mit Score-Anzeige bauen
  • Einen einfachen State Machine-Ansatz für Spielzustände nutzen
Hintergrund

Ein Spiel besteht aus mehreren Zuständen: MENU, PLAYING, PAUSED, GAME_OVER. Eine State Machine steuert, welcher Zustand aktiv ist und welche Logik läuft. Einfachste Implementierung: eine Variable current_state, die im Event-Handler und Update-Zweig geprüft wird. Fortgeschrittener: eine State-Klasse mit enter(), update(), draw(), exit()-Methoden.

Button-Implementierung: Ein Button ist ein Rect mit Label. Prüfen ob Mausposition im Rect liegt: button_rect.collidepoint(mouse_pos). Hover-Effekt: Farbe/Rahmen bei Hover ändern. Click-Handler: bei MOUSEBUTTONDOWN und collidepoint die Aktion ausführen. Pause-Overlay: halbtransparenter Surface über das Spielbild bliten (SRCALPHA oder Surface mit set_alpha()). Text zentrieren: font.render().get_rect(center=(x,y)).

State Machine & Menü-System

Code anzeigen
import pygame, sys

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock  = pygame.time.Clock()
font_h = pygame.font.SysFont("Arial", 48, bold=True)
font_m = pygame.font.SysFont("Arial", 24)
font_s = pygame.font.SysFont("Arial", 18)

STATE_MENU     = "menu"
STATE_PLAYING  = "playing"
STATE_PAUSED   = "paused"
STATE_GAMEOVER = "gameover"
current_state  = STATE_MENU
score, lives   = 0, 3

BG = (13,17,23); GREEN=(63,185,80); MUTED=(125,133,144); WHITE=(230,237,243)

class Button:
    def __init__(self, text, center, action):
        self.text   = text
        self.action = action
        surf = font_m.render(text, True, WHITE)
        self.rect   = surf.get_rect(center=center).inflate(40, 16)

    def draw(self, surface):
        mx, my = pygame.mouse.get_pos()
        hovered = self.rect.collidepoint(mx, my)
        col_fill   = (30,40,30) if hovered else (22,27,34)
        col_border = GREEN      if hovered else (48,54,61)
        pygame.draw.rect(surface, col_fill,   self.rect, border_radius=6)
        pygame.draw.rect(surface, col_border, self.rect, 2, border_radius=6)
        lbl = font_m.render(self.text, True, GREEN if hovered else WHITE)
        surface.blit(lbl, lbl.get_rect(center=self.rect.center))

    def handle(self, event):
        if event.type == pygame.MOUSEBUTTONDOWN and event.button == 1:
            if self.rect.collidepoint(event.pos):
                self.action()

def start_game():
    global current_state, score, lives
    current_state = STATE_PLAYING; score = 0; lives = 3

def quit_game(): pygame.quit(); sys.exit()

btn_start = Button("Spielen",  (400, 300), start_game)
btn_quit  = Button("Beenden",  (400, 360), quit_game)

pause_surf = pygame.Surface((800,600), pygame.SRCALPHA)
pause_surf.fill((0,0,0,140))

running = True
while running:
    dt = clock.tick(60) / 1000
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False
        if current_state == STATE_MENU:
            btn_start.handle(event); btn_quit.handle(event)
        if current_state == STATE_PLAYING:
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_ESCAPE: current_state = STATE_PAUSED
                if event.key == pygame.K_SPACE:  score += 10
                if event.key == pygame.K_h:      lives -= 1
        if current_state == STATE_PAUSED:
            if event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
                current_state = STATE_PLAYING
        if current_state == STATE_GAMEOVER:
            if event.type == pygame.KEYDOWN: current_state = STATE_MENU

    if current_state == STATE_PLAYING and lives <= 0:
        current_state = STATE_GAMEOVER

    screen.fill(BG)
    if current_state == STATE_MENU:
        t = font_h.render("MEIN SPIEL", True, GREEN)
        screen.blit(t, t.get_rect(center=(400, 200)))
        btn_start.draw(screen); btn_quit.draw(screen)
    elif current_state == STATE_PLAYING:
        screen.blit(font_m.render(f"Score: {score}  Leben: {'♥ '*lives}", True, WHITE), (20,20))
        screen.blit(font_s.render("SPACE=+Score  H=Treffer  ESC=Pause", True, MUTED), (20,560))
    elif current_state == STATE_PAUSED:
        screen.blit(font_m.render(f"Score: {score}", True, WHITE), (20,20))
        screen.blit(pause_surf, (0,0))
        t = font_h.render("PAUSE", True, WHITE)
        screen.blit(t, t.get_rect(center=(400,280)))
        screen.blit(font_s.render("ESC zum Fortfahren", True, MUTED), font_s.render("ESC zum Fortfahren",True,MUTED).get_rect(center=(400,340)))
    elif current_state == STATE_GAMEOVER:
        t = font_h.render("GAME OVER", True, (255,123,114))
        screen.blit(t, t.get_rect(center=(400,250)))
        s = font_m.render(f"Score: {score}", True, WHITE)
        screen.blit(s, s.get_rect(center=(400,320)))
        screen.blit(font_s.render("Beliebige Taste für Menü", True, MUTED), font_s.render("Beliebige Taste",True,MUTED).get_rect(center=(400,370)))

    pygame.display.flip()

pygame.quit(); sys.exit()

State-Variablen klar benennen (STATE_MENU statt "menu") verhindert Tipp-Fehler. Eine echte State-Klasse mit enter/exit lohnt sich ab 5+ Zuständen.

Aufgabe

Implementiere ein vollständiges Menü-System mit Hauptmenü (2 Buttons), Pause-Overlay, und Game-Over-Screen. Nutze eine State-Variable für klare Zustandstrennung.

Anforderungen
  1. 4 Spielzustände: MENU, PLAYING, PAUSED, GAME_OVER
  2. Button-Klasse: Hover-Effekt, Click-Handler
  3. Pause: ESC toggelt, halbtransparentes Overlay
  4. Game-Over-Screen zeigt finalen Score
  5. State-Übergänge korrekt und vollständig
Akzeptanzkriterien
  • Alle Zustände erreichbar und korrekt
  • Buttons reagieren auf Hover und Klick
  • Pause hält Spiellogik an, Overlay sichtbar
