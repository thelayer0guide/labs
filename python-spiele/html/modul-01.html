pygame Setup & Game Loop

Cheat Sheets
python
Lernziele
  • pygame installieren und ein Fenster öffnen
  • Den Game-Loop-Grundriss verstehen und implementieren
  • Mit pygame.time.Clock die Framerate steuern
  • Das Programm sauber beenden
Hintergrund

Spieleentwicklung unterscheidet sich von klassischen Programmen durch einen zentralen Mechanismus: den Game Loop. Er läuft kontinuierlich und besteht aus drei Phasen — Events verarbeiten, Zustand aktualisieren, Bild rendern — bevor der Zyklus von vorne beginnt. pygame ist die Standard-Python-Bibliothek dafür: sie abstrahiert OpenGL und SDL2 zu einer einfach nutzbaren API.

Installation: pip install pygame. pygame.init() startet alle Subsysteme (Display, Sound, Eingabe). pygame.display.set_mode((width, height)) erzeugt das Fenster. pygame.display.flip() übertragt den Framebuffer auf den Bildschirm. pygame.time.Clock().tick(60) limitiert auf 60 FPS und gibt die vergangene Zeit in ms zurück. pygame.quit() + sys.exit() beenden sauber.

Schlüsselkonzepte

Minimaler Game Loop

Code anzeigen
import pygame, sys

pygame.init()

WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Mein erstes Spiel")

clock  = pygame.time.Clock()
running = True

while running:
    # 1. Events
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
            running = False

    # 2. Update (noch leer)

    # 3. Render
    screen.fill((13, 17, 23))       # Hintergrundfarbe
    pygame.display.flip()

    clock.tick(60)                  # max. 60 FPS

pygame.quit()
sys.exit()

Der Loop läuft, solange running True ist. clock.tick(60) schläft die restliche Frame-Zeit — ohne ihn würde die CPU auf 100 % laufen.

Aufgabe

Erstelle ein pygame-Projekt mit sauberer Ordnerstruktur. Implementiere den Game Loop mit Framerate-Kontrolle. Das Fenster soll einen Titel tragen und auf ESC und das Schließen reagieren.

Anforderungen
  1. pip install pygame, Import prüfen
  2. Fenster: 800×600, Titel gesetzt
  3. Game Loop: Events → Update → Render korrekt strukturiert
  4. ESC und QUIT-Event schließen das Programm
  5. Clock.tick(60): FPS wird im Fenstertitel angezeigt (pygame.display.set_caption(f"FPS: {clock.get_fps():.0f}"))
Akzeptanzkriterien
  • Fenster öffnet sich ohne Fehler
  • Programm läuft stabil bei ~60 FPS
  • ESC und Schließen beenden das Programm sauber
