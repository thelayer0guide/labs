Grafik & Zeichnen

Cheat Sheets
python
Lernziele
  • Pygame-Zeichenfunktionen für Formen und Linien einsetzen
  • Surfaces erstellen, befüllen und auf den Screen bliten
  • Das pygame-Koordinatensystem verstehen (Y-Achse invertiert)
  • Text mit pygame.font rendern und positionieren
Hintergrund

pygame rendert alles auf Surfaces — Rechtecke aus Pixeln, auf denen man zeichnen kann. screen ist selbst eine Surface. pygame.draw bietet Zeichenfunktionen: circle, rect, line, polygon, ellipse. Alle nehmen eine Surface, eine Farbe und Parameter. Farben als RGB-Tupel: (255, 0, 0) = Rot. Alpha-Kanal: pygame.Surface((w,h), pygame.SRCALPHA) für Transparenz.

Koordinatensystem: Ursprung (0,0) ist oben links. X wächst nach rechts, Y nach unten — anders als in der Mathematik. pygame.Rect ist das zentrale Objekt für Position und Kollision: Rect(x, y, width, height). Attribute: .left, .top, .right, .bottom, .center, .centerx, .centery, .width, .height. Text: pygame.font.SysFont("Arial", 24) oder eigene TTF-Datei laden.

Schlüsselkonzepte

Formen & Text zeichnen

Code anzeigen
import pygame, sys

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock  = pygame.time.Clock()

BG     = (13, 17, 23)
WHITE  = (230, 237, 243)
GREEN  = (63, 185, 80)
BLUE   = (88, 166, 255)
RED    = (255, 123, 114)

font_big  = pygame.font.SysFont("JetBrainsMono", 32, bold=True)
font_small = pygame.font.SysFont("Arial", 18)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT: running = False

    screen.fill(BG)

    # Rechteck
    rect = pygame.Rect(100, 100, 200, 80)
    pygame.draw.rect(screen, GREEN, rect, border_radius=8)
    pygame.draw.rect(screen, WHITE, rect, 2, border_radius=8)  # Rahmen

    # Kreis
    pygame.draw.circle(screen, BLUE, (500, 150), 60)
    pygame.draw.circle(screen, WHITE, (500, 150), 60, 2)       # Outline

    # Linie & Polygon
    pygame.draw.line(screen, RED, (50, 300), (750, 300), 2)
    pygame.draw.polygon(screen, RED, [(400,350),(350,450),(450,450)])

    # Text rendern
    title = font_big.render("pygame Grafik", True, WHITE)
    screen.blit(title, (100, 20))  # Position: linke obere Ecke

    # Text zentrieren
    info  = font_small.render("Koordinaten: (0,0) = oben links", True, (125,133,144))
    rect_i = info.get_rect(center=(400, 540))
    screen.blit(info, rect_i)

    pygame.display.flip()
    clock.tick(60)

pygame.quit(); sys.exit()

blit() kopiert eine Surface auf eine andere. get_rect(center=...) gibt ein Rect zurück, dessen Mitte an der angegebenen Position liegt.

Aufgabe

Erstelle eine "Szene" mit mindestens fünf verschiedenen Zeichenelementen: Rechtecke, Kreise, Linien, Text und eine Surface mit Alpha-Transparenz. Zeige das Koordinatensystem durch Debug-Text an.

Anforderungen
  1. 5+ verschiedene pygame.draw-Funktionen eingesetzt
  2. Text mit SysFont gerendert und mit get_rect(center=) zentriert
  3. Farben als Konstanten in settings.py definiert
  4. Alpha-Surface: pygame.Surface mit SRCALPHA erstellt
  5. Rect-Objekte für Positions-Management genutzt
Akzeptanzkriterien
  • Szene rendert ohne Fehler
  • Text korrekt positioniert
  • Alpha-Transparenz sichtbar funktionierend
