Dateiberechtigungen (chmod/ACL)

Cheat Sheets
linux
Lernziele
  • Das rwx-Berechtigungsmodell für Benutzer, Gruppe und Others verstehen
  • Oktalnotation für chmod beherrschen
  • SUID, SGID und Sticky-Bit erklären
  • POSIX-ACLs mit getfacl und setfacl einsetzen
Hintergrund

Linux-Dateiberechtigungen bestehen aus drei Triaden: Besitzer (User), Gruppe (Group), Alle anderen (Others). Jede Triade hat Read (r=4), Write (w=2), Execute (x=1). Die Oktalnotation fasst eine Triade in einer Ziffer zusammen: rwx = 7, rw- = 6, r-x = 5. chmod 755 bedeutet rwxr-xr-x — Besitzer darf alles, Gruppe und Others dürfen lesen und ausführen.

POSIX-ACLs (Access Control Lists) erweitern das klassische Modell: statt einer Gruppe können mehrere Benutzer/Gruppen unterschiedliche Rechte erhalten. getfacl zeigt ACLs, setfacl setzt sie. Im Kontext von Systemhärtung ist es wichtig zu wissen: zu freizügige Berechtigungen (777, world-writable) sind ein häufiger Audit-Fund und Einfallstor für Angreifer.

Schlüsselkonzepte

chmod & Berechtigungen

Code anzeigen
# Berechtigungen anzeigen
ls -la /etc/passwd
# -rw-r--r-- 1 root root 2847 Jan 1 12:00 /etc/passwd
# ^^^^^^^^^^ Berechtigungen

# chmod Oktal
chmod 644 datei.txt   # rw-r--r--
chmod 755 script.sh   # rwxr-xr-x
chmod 600 private.key # rw-------

# chmod symbolisch
chmod u+x datei.sh    # User: +Execute
chmod go-w datei.txt  # Group+Others: -Write
chmod a=r datei.txt   # All: Read only

# Besitzer ändern
chown alice:alice datei.txt
chown -R www-data:www-data /var/www/

SUID/SGID/Sticky & ACL

Code anzeigen
# Sticky Bit setzen (nur Besitzer kann löschen)
chmod 1777 /tmp
ls -la / | grep tmp
# drwxrwxrwt ... tmp (t = sticky)

# SUID setzen
chmod 4755 programm  # rwsr-xr-x (s = SUID)

# POSIX ACL
getfacl datei.txt
setfacl -m u:bob:rw datei.txt   # Bob: rw
setfacl -m g:devs:rx datei.txt  # Group devs: rx
getfacl datei.txt

# ACL entfernen
setfacl -x u:bob datei.txt
setfacl -b datei.txt  # alle ACLs

Das Sticky-Bit auf /tmp verhindert, dass Benutzer Dateien anderer löschen — auch wenn /tmp world-writable ist. Ohne Sticky-Bit könnten race-condition-basierte TOCTOU-Angriffe /tmp ausnutzen.

Aufgabe

Setze verschiedene Berechtigungen auf Testdateien und prüfe die Auswirkungen. Konfiguriere POSIX-ACLs für ein Verzeichnis mit mehreren Benutzern.

Anforderungen
  1. Oktalnotation für 644, 755, 700, 777 auswendig erklären
  2. chmod und chown auf mindestens 5 Dateien anwenden
  3. Sticky-Bit auf /tmp und seine Wirkung erklären
  4. POSIX-ACL mit setfacl konfigurieren und mit getfacl prüfen
  5. World-writable Dateien mit find finden und bewerten
Akzeptanzkriterien
  • Oktalnotation korrekt angewendet
  • POSIX-ACL konfiguriert und verifiziert
  • World-writable Dateien analysiert
