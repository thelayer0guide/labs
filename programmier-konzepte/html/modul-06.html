Datenstrukturen: Listen & Dicts

Cheat Sheets
python
Lernziele
  • Listen (Arrays) erstellen, slicen und manipulieren
  • Dictionaries für Key-Value-Speicherung nutzen
  • Sets und Tuples als weitere Datenstrukturen kennen
  • Zeitkomplexität von Datenstruktur-Operationen einschätzen
Hintergrund

Python-Listen sind geordnete, veränderliche Sequenzen beliebiger Typen. Slicing [start:end:step] ist ein mächtiges Feature. Dictionaries (dicts) sind ungeordnete Key-Value-Stores — der Zugriff erfolgt in O(1) via Hash-Tabelle. Sets sind ungeordnete Mengen ohne Duplikate. Tuples sind unveränderliche Listen — ideal für Konfigurationsdaten und Rückgabewerte.

Im Security-Kontext sind Datenstrukturen überall: eine IP-Blacklist als Set (O(1) Lookup), ein Log-Parser gibt eine Liste von Dicts zurück, eine Konfiguration ist ein verschachteltes Dict. Die Wahl der richtigen Datenstruktur beeinflusst Performance drastisch: if ip in ip_list ist O(n) als Liste, O(1) als Set.

Schlüsselkonzepte

Listen & Dicts

Code anzeigen
# Listen
liste = [1, 2, 3, 4, 5]
liste.append(6)
liste.insert(0, 0)
liste.remove(3)
print(liste[1:4])    # Slice: [1, 2, 3]
print(liste[::-1])   # umgekehrt

# Dictionary
benutzer = {
    "name": "Alice",
    "alter": 30,
    "rollen": ["admin", "user"]
}
benutzer["email"] = "alice@example.com"
benutzer.get("passwort", "nicht gesetzt")

for key, val in benutzer.items():
    print(f"{key}: {val}")

# Set und Tuple
ips = {"192.168.1.1", "10.0.0.1"}
ips.add("172.16.0.1")
print("192.168.1.1" in ips)  # O(1)!
koords = (48.1, 11.6)  # unveränderlich
