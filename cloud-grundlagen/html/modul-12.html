Cloud-Kosten & FinOps

Cheat Sheets
bash
Lernziele
  • AWS-Preismodell (Pay-as-you-go, Reserved, Spot) verstehen
  • AWS Cost Explorer und Billing Dashboard nutzen
  • Häufige Kosten-Fallen erkennen und vermeiden
  • Tagging-Strategie für Kostenzuordnung einsetzen
Hintergrund

Cloud-Kosten können schnell außer Kontrolle geraten — "Cloud-Bill-Shock" ist real. AWS-Preismodelle: On-Demand (teuerste, flexibel), Reserved Instances (1-3 Jahre Commitment, bis 75% günstiger), Spot Instances (überschüssige Kapazität, bis 90% günstiger, aber kann jederzeit beendet werden), Savings Plans (flexibler als Reserved). Kostentreiber: vergessene laufende EC2-Instanzen, teurer RDS-Traffic, Load-Balancer ohne Traffic, NatGateway-Traffic.

FinOps (Financial Operations) ist die Praxis, Cloud-Kosten zu verstehen, zu optimieren und zu steuern. AWS Cost Explorer: grafische Analyse der Kosten nach Service, Region, Tag. AWS Budgets: Alarme bei Überschreitung definierter Budgetgrenzen. Tagging: jede Ressource erhält Tags (Projekt, Team, Umgebung) — ermöglicht Kostenzuordnung. Im Security-Kontext: ungewöhnlich hohe Kosten können auf Crypto-Mining nach einer Kompromittierung hinweisen (häufiger Angriff auf kompromittierte AWS-Credentials).

Schlüsselkonzepte

Kosten-Analyse mit AWS CLI

Code anzeigen
# AWS Billing
aws ce get-cost-and-usage \
  --time-period Start=2024-01-01,End=2024-02-01 \
  --granularity MONTHLY \
  --metrics "BlendedCost" \
  --group-by Type=DIMENSION,Key=SERVICE

# Kosten nach Tag
aws ce get-cost-and-usage \
  --time-period Start=2024-01-01,End=2024-02-01 \
  --granularity MONTHLY \
  --metrics "UnblendedCost" \
  --group-by Type=TAG,Key=Projekt

# Ressourcen-Tags prüfen
aws ec2 describe-instances \
  --query "Reservations[].Instances[].[InstanceId,Tags]"

# Unbenutzte Ressourcen finden
aws ec2 describe-instances \
  --filters "Name=instance-state-name,Values=stopped"
aws ec2 describe-volumes \
  --filters "Name=status,Values=available"  # Ungenutzte Volumes
aws ec2 describe-elastic-ips               # Ungenutzte Elastic IPs

# Budget einrichten
aws budgets create-budget \
  --account-id 123456789 \
  --budget file://budget.json \
  --notifications-with-subscribers file://notifications.json
Aufgabe

Analysiere deine AWS-Kosten mit Cost Explorer: identifiziere die teuersten Services und nicht mehr benötigte Ressourcen (gestoppte EC2, ungenutzte Volumes).

Anforderungen
  1. AWS-Preismodelle: On-Demand, Reserved, Spot vergleichen
  2. Cost Explorer: Kosten nach Service aufschlüsseln
  3. 3 häufige Cloud-Kosten-Fallen nennen
  4. Tagging-Strategie: welche Tags sind essentiell?
  5. Kompromittierte Credentials und Crypto-Mining: Erkennung
Akzeptanzkriterien
  • Kosten-Analyse durchgeführt
  • Ungenutzte Ressourcen identifiziert
  • Budget-Alarm konfiguriert
