Incident Response für AD-Kompromittierung

Cheat Sheets
Active Directory Windows
Lernziele
  • IR-Playbook für AD-Kompromittierung abarbeiten
  • Kompromittierte Accounts identifizieren und isolieren
  • Forensische Daten sichern (Logs, RAM, AD-Snapshot)
  • Credential-Reset-Prozess für alle Tier-0-Accounts durchführen
Hintergrund

Active Directory Incident Response folgt einem klaren Prozess: (1) Identify — was ist kompromittiert?, (2) Contain — Zugriff unterbinden, (3) Eradicate — Persistenz entfernen, (4) Recover — System wiederherstellen, (5) Lessons Learned.

Bei vollständiger Domänen-Kompromittierung (Domain Admin erreicht) muss angenommen werden, dass alle Credentials kompromittiert sind. krbtgt zweimalige Rotation ist Pflicht. Neue DCs ausrollen ist oft sicherer als bestehende zu bereinigen.

Schlüsselkonzepte

IR-Checkliste AD-Kompromittierung

Code anzeigen
# IMMEDIATE:
# 1. Netzwerk-Isolation der betroffenen Systeme
# 2. Alle Tier-0-Accounts sperren (außer Notfall-Account)
# 3. krbtgt ZWEIMAL rotieren
# 4. Alle Admin-Passwörter zurücksetzen
# 5. Scheduled Tasks, Services, Run Keys auf DCs prüfen

# FORENSIK:
# 6. RAM-Dump von DCs
# 7. AD-Snapshot sichern (ntdsutil)
# 8. Event-Logs sichern und extern speichern

# ERADIKATION:
# 9. Alle unbekannten Admin-Accounts entfernen
# 10. ACLs auf Anomalien prüfen (BloodHound)

AD-Snapshot sichern

Code anzeigen
# ntdsutil: AD-Datenbank sichern
ntdsutil "activate instance ntds" "ifm" "create full C:\ADBackup" quit quit

# PowerShell: AD-Replikations-Metadaten
Get-ADReplicationUpToDatenessVectorTable -Target DC01

# Event-Logs exportieren:
wevtutil epl Security C:\Forensics\Security.evtx
wevtutil epl "Microsoft-Windows-Sysmon/Operational" C:\Forensics\Sysmon.evtx
Aufgabe

Simuliere einen vollständigen AD-IR-Vorfall: das Red Team hat Domain Admin erreicht. Führe den vollständigen IR-Prozess durch: Identifikation, Eindämmung, Beseitigung, Wiederherstellung.

Anforderungen
  1. Kompromittierte Accounts über Logs identifizieren
  2. Betroffene Systeme netzwerk-isolieren
  3. krbtgt zweimalig rotieren
  4. Forensik-Daten sichern (Logs, AD-Snapshot)
  5. Alle Admin-Passwörter zurücksetzen
  6. Persistenz-Checks: Tasks, Services, Run Keys
Akzeptanzkriterien
  • krbtgt rotiert (zweimal)
  • Forensik-Daten gesichert
  • Alle Persistenz-Mechanismen entfernt
