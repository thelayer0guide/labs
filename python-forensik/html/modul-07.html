FileTimeline

Cheat Sheets

Lernziele

  • Große Verzeichnisbäume speichereffizient mit Generator-Expressions traversieren
  • Chronologisch sortierte Ereignisliste aus Filesystem-Metadaten aufbauen
  • CSV-Export mit csv.DictWriter inkl. korrekter Timestamp-Serialisierung
  • Einfachen HTML-Report mit Inline-CSS generieren (kein Template-Engine)
  • Zeitraumfilter mit datetime-Vergleich und Dateiendungs-Filter implementieren
Hintergrund

In der digitalen Forensik ist die Rekonstruktion einer Ereignis-Timeline zentral. Wann wurde eine Datei erstellt? Wann zuletzt modifiziert? Wann zuletzt gelesen? Diese drei Zeitstempel (mtime/atime/ctime) sind im Inodes gespeichert und über os.stat() direkt aus Python abrufbar.

FileTimeline scanst ein Verzeichnis, liest alle Zeitstempel, sortiert chronologisch und macht die Abfolge von Dateioperationen sichtbar. Das ist das erste Werkzeug bei der Analyse eines kompromittierten Webservers: Wann wurde evil.php angelegt? Wurden danach weitere Dateien verändert?

Der HTML-Export ist dabei mehr als nur Optik — ein standalone-HTML mit Inline-CSS ist selbst auf forensisch isolierten Systemen ohne Browser-Extension aufrufbar und kann einfach in Incident-Reports eingebettet werden.

Schlüsselkonzepte

Inode-Zeitstempel lesen

from pathlib import Path
from datetime import datetime

def file_timestamps(path: Path) -> dict:
    s = path.stat()
    return {
        'path':  str(path),
        'size':  s.st_size,
        'mtime': datetime.fromtimestamp(s.st_mtime),  # last modified
        'atime': datetime.fromtimestamp(s.st_atime),  # last accessed
        'ctime': datetime.fromtimestamp(s.st_ctime),  # inode changed (not "created"!)
        'ext':   path.suffix.lower(),
    }

Zeitleiste aufbauen

def build_timeline(root: Path, ts_field: str = 'mtime',
                   since=None, until=None, exts=None):
    events = []
    for p in root.rglob('*'):
        if not p.is_file():
            continue
        if exts and p.suffix.lower() not in exts:
            continue
        entry = file_timestamps(p)
        ts = entry[ts_field]
        if since and ts < since:
            continue
        if until and ts > until:
            continue
        events.append(entry)
    return sorted(events, key=lambda e: e[ts_field])

HTML-Report generieren

def render_html(events: list[dict], title: str) -> str:
    rows = '\n'.join(
        f'<tr><td>{e["mtime"].strftime("%Y-%m-%d %H:%M:%S")}</td>'
        f'<td>{e["ext"] or "—"}</td>'
        f'<td style="font-family:monospace">{e["path"]}</td>'
        f'<td style="text-align:right">{e["size"]:,}</td></tr>'
        for e in events
    )
    return f"""<!DOCTYPE html>
<html><head><meta charset="UTF-8"><title>{title}</title>
<style>body{{font-family:monospace;background:#0d1117;color:#e6edf3}}
table{{border-collapse:collapse;width:100%}}
th,td{{padding:6px 10px;border-bottom:1px solid #30363d;text-align:left}}
th{{color:#58a6ff}}</style></head>
<body><h1>{title}</h1><table>
<tr><th>Timestamp</th><th>Ext</th><th>Path</th><th>Size</th></tr>
{rows}</table></body></html>"""
Aufgabe — timeline.py
# Alle Dateien nach mtime sortiert
timeline.py /var/www

# Nur PHP-Dateien, letzte 48 Stunden
timeline.py /var/www --ext .php --since "2025-06-17 00:00"

# Nach atime (Zugriffszeitpunkt) statt mtime
timeline.py /home/user --ts atime --since "2025-06-19 08:00"

# CSV exportieren
timeline.py /var/www --format csv --out timeline.csv

# HTML-Report erstellen
timeline.py /var/www --format html --out report.html --title "Incident 2025-06-19"

Wichtig: ctime ist auf Linux nicht der Erstellungszeitpunkt, sondern der Zeitpunkt der letzten Inode-Änderung (inkl. Berechtigungsänderungen). Das sollte in der Dokumentation des Tools klargestellt sein.

Anforderungen
  • Alle drei Zeitstempel (mtime, atime, ctime) werden gelesen und angezeigt
  • --ts wählt den Sortierschlüssel (mtime ist Standard)
  • --since / --until filtern nach dem gewählten Zeitstempel
  • --ext nimmt mehrere Endungen entgegen (kommagetrennt oder mehrfach angegeben)
  • CSV-Export enthält alle Spalten inkl. ISO-Zeitstempel und Dateigröße in Bytes
  • HTML-Export ist standalone (kein externes CSS/JS) und im Browser direkt öffenbar
  • Nur stdlib
Akzeptanzkriterien
  1. Timeline von /var/www mit 5.000 Dateien läuft in unter 3 Sekunden durch
  2. Eine bekannte neu erstellte Datei erscheint an der korrekten chronologischen Position
  3. CSV kann mit LibreOffice Calc geöffnet werden ohne Zeichensatz-Fehler
  4. HTML-Report ist im Browser aufrufbar und zeigt alle Dateien in richtiger Reihenfolge
  5. Tool gibt sinnvolle Meldung aus wenn --since nach --until liegt
