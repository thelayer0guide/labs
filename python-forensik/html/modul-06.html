ErrorCorrelator

Tool-Output: errcorr.py — zeitliche Fehlerkorrelation über mehrere Logquellen
Voraussetzungen: datetime, heapq, regex, collections.defaultdict
Cheat Sheets
python regex
Lernziele
  • Mehrere Logdateien gleichzeitig parsen und in eine gemeinsame Zeitleiste zusammenführen
  • heapq.merge() für zeitgeordnetes Zusammenführen mehrerer sortierten Streams nutzen
  • Zeitfenster-Clustering: Ereignisse innerhalb von N Sekunden als Gruppe behandeln
  • Ähnliche Fehlermeldungen mit einfachem Token-Vergleich (Jaccard-Ähnlichkeit) clustern
  • collections.Counter und defaultdict für Häufigkeitsanalysen einsetzen
  • Kausalitäts-Heuristiken: welche Fehler gehen anderen konsistent voraus?
Hintergrund

Ein Datenbankfehler in db.log taucht 200ms bevor ein Application-Error in app.log erscheint, der dann einen Nginx-502 in access.log auslöst. Das ist eine kausale Kette — aber sie manuell über drei Logdateien hinweg zu verfolgen ist zeitraubend und fehleranfällig.

ErrorCorrelator schafft eine einheitliche Zeitachse aus allen Quellen und markiert Ereignisse, die sich zeitlich überlappen (Zeitfenster konfigurierbar). Das ist kein Machine-Learning — es ist simples, zuverlässiges Zeitfenster-Clustering mit klaren Regeln und erklärbaren Ausgaben.

Dieses Modul ist das komplexeste des Kurses, weil es Streaming (speichereffizient), Zeitvergleiche (Timezone-Handling) und eine nicht-triviale Datenstruktur (Priority Queue über mehrere Iteratoren) kombiniert.

def merged_events(sources: list[tuple[str, str]]):
    # sources = [(filename, format), ...]
    iterators = []
    for path, fmt in sources:
        iterators.append(parse_log_stream(path, fmt))
    # heapq.merge sortiert nach erstem Element — muss datetime sein
    yield from heapq.merge(*iterators, key=lambda e: e['ts'])

Zeitfenster-Clustering

Code anzeigen
from datetime import timedelta

def cluster_by_window(events, window_sec: int = 30):
    window = timedelta(seconds=window_sec)
    cluster: list = []
    for ev in events:
        if not cluster or ev['ts'] - cluster[-1]['ts'] <= window:
            cluster.append(ev)
        else:
            if len(cluster) > 1:
                yield cluster
            cluster = [ev]
    if len(cluster) > 1:
        yield cluster

Einfaches Message-Clustering per Jaccard

Code anzeigen
def tokenize(msg: str) -> set[str]:
    import re
    # Zahlen normalisieren damit "error on line 42" == "error on line 7"
    msg = re.sub(r'\d+', 'N', msg.lower())
    return set(re.findall(r'[a-z_]+', msg))

def jaccard(a: set, b: set) -> float:
    if not a or not b:
        return 0.0
    return len(a & b) / len(a | b)

def find_similar(messages: list[str], threshold=0.6) -> list[list[int]]:
    groups, assigned = [], set()
    for i, m in enumerate(messages):
        if i in assigned:
            continue
        group = [i]
        for j, n in enumerate(messages[i+1:], i+1):
            if j not in assigned and jaccard(tokenize(m), tokenize(n)) >= threshold:
                group.append(j); assigned.add(j)
        groups.append(group); assigned.add(i)
    return groups
Aufgabe — errcorr.py
Code anzeigen
# Drei Logdateien korrelieren, 30-Sekunden-Fenster
errcorr.py app.log db.log nginx/access.log --window 30

# Nur ERROR-Level-Ereignisse, 60s-Fenster
errcorr.py *.log --level error --window 60

# Ähnliche Fehlermeldungen clustern
errcorr.py app.log --cluster-messages --threshold 0.7

# Ausgabe als JSON für ForensicKit
errcorr.py app.log db.log --format json > correlations.json

Ausgabe: Für jede Korrelationsgruppe werden Zeitraum, beteiligte Quellen, Anzahl Ereignisse und die häufigste Nachricht angezeigt.

Tipp: Logdateien sind oft nicht perfekt sortiert. Behandle fehlerhaft sortierte Einträge mit einem kleinen Puffer (deque der letzten N Einträge) statt alles vorab zu laden.

Anforderungen
  • Mehrere Logdateien werden zeitzeilengeordnet zusammengeführt
  • Zeitfenster ist per --window SEKUNDEN konfigurierbar
  • Gruppen mit nur einem Ereignis werden standardmäßig nicht angezeigt
  • --level filtert nach Fehlerschwere vor der Korrelation
  • --cluster-messages gruppiert ähnliche Nachrichten zusätzlich
  • Memory-footprint: auch 1GB-Logdateien werden gestreamt, nicht komplett geladen
  • Nur stdlib
Akzeptanzkriterien
  1. Zwei Logdateien mit bekannten zeitlich-überlappenden Fehlergruppen werden korrekt korreliert
  2. Das Tool läuft mit 3 Logdateien à 100MB ohne out-of-memory
  3. Ausgabe zeigt für jede Gruppe: Zeitraum, Quelldateien, Ereignisanzahl, häufigste Nachricht
  4. --format json produziert valides JSON
  5. Einzelne Fehler-Zeilen ohne Zeitstempel werden übersprungen, nicht abgebrochen
