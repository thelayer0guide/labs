LogParser

Tool-Output: logparse.py — universeller CLI-Logreader
Voraussetzungen: Python Grundlagen, regex, argparse
Cheat Sheets
python regex bash
Lernziele
  • Verschiedene Logformate (syslog, combined access log, journald) mit Regex parsen
  • Zeitstempel-Parsing mit datetime.strptime und Zeitraumfilter implementieren
  • Strukturierte Ausgabe tabellarisch oder als JSON realisieren
  • Flexibles CLI mit argparse mit mehreren Subkommandos aufbauen
  • Generator-Funktionen für speichereffizientes Lesen großer Logdateien einsetzen
  • Farbige Konsolen-Ausgabe mit ANSI-Escapes ohne externe Bibliotheken umsetzen
Hintergrund

Logdateien sind der primäre Informationskanal bei der Fehleranalyse und Incident Response. Das Problem: Jeder Dienst schreibt sein eigenes Format. grep und awk sind mächtig, aber schwer kombinierbar und nicht wiederverwendbar als Teil eines größeren Workflows.

Ein eigener LogParser löst genau das: einheitliche Schnittstelle für verschiedene Formate, filterbar nach Zeitraum, Log-Level, IP-Adresse oder beliebigem Stichwort — und maschinenlesbarer JSON-Output für die Weiterverarbeitung durch andere Tools.

Das Tool soll im Alltag ersetzbar sein für schnelle grep -E "ERROR" /var/log/syslog | tail -100-Einzeiler — nur strukturierter, filterbar und mit Summary-Funktion.

Schlüsselkonzepte

Logformate und Regex-Muster

import re
from datetime import datetime

# syslog: "Jun 19 14:23:01 hostname sshd[1234]: Failed password..."
SYSLOG_RE = re.compile(
    r'(?P<month>\w{3})\s+(?P<day>\d+)\s+(?P<time>[\d:]+)\s+'
    r'(?P<host>\S+)\s+(?P<proc>\S+?)(?:\[(?P<pid>\d+)\])?\s*:\s+(?P<msg>.+)'
)

# nginx combined: 192.168.1.1 - - [19/Jun/2025:14:23:01 +0000] "GET / HTTP/1.1" 200 1234
ACCESS_RE = re.compile(
    r'(?P<ip>[\d.]+) \S+ \S+ \[(?P<time>[^\]]+)\] '
    r'"(?P<method>\w+) (?P<path>\S+)[^"]*" (?P<status>\d+) (?P<size>\d+)'
)

Speichereffizientes Lesen mit Generator

def parse_lines(filepath: str, pattern: re.Pattern):
    with open(filepath, encoding='utf-8', errors='replace') as f:
        for line in f:                   # streamt Zeile für Zeile, kein list()
            m = pattern.match(line.rstrip())
            if m:
                yield m.groupdict()

Zeitraumfilter

def in_range(entry: dict, since: datetime | None, until: datetime | None) -> bool:
    ts = entry.get('timestamp')
    if ts is None:
        return True
    if since and ts < since:
        return False
    if until and ts > until:
        return False
    return True

CLI-Grundstruktur

import argparse, sys, json

def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(description='Universeller Logparser')
    p.add_argument('file', help='Pfad zur Logdatei')
    p.add_argument('--format', choices=['syslog','access','auto'], default='auto')
    p.add_argument('--level', help='Filter: ERROR|WARN|INFO (syslog)')
    p.add_argument('--ip', help='Filter: IP-Adresse (access log)')
    p.add_argument('--since', help='Von: YYYY-MM-DD HH:MM')
    p.add_argument('--until', help='Bis:  YYYY-MM-DD HH:MM')
    p.add_argument('--out', choices=['table','json','summary'], default='table')
    p.add_argument('-n', type=int, default=0, help='Letzte N Zeilen (0 = alle)')
    return p
Aufgabe — logparse.py

Baue einen universellen Logparser der folgende Formate erkennt und verarbeitet:

  • syslog — /var/log/syslog, /var/log/auth.log
  • nginx/apache access log — combined log format
  • auto — Format an der ersten Zeile erkennen

Das fertige Tool soll sich wie folgt aufrufen lassen:

# Alle SSH-Fehler der letzten Stunde
logparse.py /var/log/auth.log --level ERROR --since "2025-06-19 13:00"

# Top-10 IPs nach Anzahl Requests
logparse.py /var/log/nginx/access.log --out summary

# Alle 404-Antworten als JSON
logparse.py access.log --format access --out json | jq '[.[] | select(.status=="404")]'

# Letzte 50 Einträge tabellarisch
logparse.py /var/log/syslog -n 50 --out table

Kein pandas, kein tabulate — Tabellenformatierung mit str.ljust() / str.rjust() selbst implementieren.

Anforderungen
  • syslog- und access-log-Format werden korrekt geparst
  • --format auto erkennt das Format anhand der ersten nicht-leeren Zeile
  • Zeitraumfilter --since / --until funktionieren mit Format YYYY-MM-DD HH:MM
  • Ausgabemodi table, json und summary sind implementiert
  • --level filtert syslog-Zeilen nach Schlüsselwort (case-insensitive)
  • --ip filtert access-log-Zeilen nach exakter IP-Adresse
  • -n N limitiert die Ausgabe auf die letzten N Treffer
  • Nur stdlib — keine Drittbibliotheken
Akzeptanzkriterien
  1. Das Tool parst /var/log/auth.log ohne Exception, auch wenn einzelne Zeilen nicht matchen
  2. --out json produziert valides JSON (prüfbar mit python -m json.tool)
  3. --out summary zeigt mindestens: Gesamtzeilen, Treffer, Top-5-Quellen (IPs oder Prozesse)
  4. Tabellenausgabe ist bei verschiedenen Terminalbreiten nicht kaputt (keine überlappenden Spalten)
  5. Das Tool ist als direkt ausführbares Skript verwendbar: chmod +x logparse.py && ./logparse.py
