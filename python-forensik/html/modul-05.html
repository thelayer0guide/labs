DataProfiler

Tool-Output: dataprofiler.py — CSV/JSON-Datenprofiler mit Ausreißer-Erkennung
Voraussetzungen: csv, json, statistics, argparse, pathlib
Cheat Sheets
python json
Lernziele
  • CSV und JSON mit Stdlib lesen und in ein einheitliches Spalten-Dict-Format überführen
  • Datentypen automatisch inferieren: numerisch, kategorial, boolescher, Datum
  • Statistische Kennzahlen ohne NumPy/Pandas berechnen: Median, Varianz, Std. Abweichung
  • Ausreißer per IQR (Interquartile Range) und Z-Score erkennen
  • Null-/Leer-Anteile und Kardinalität (unique-count) pro Spalte berechnen
  • Profilbericht als JSON und als formatierte Konsolen-Übersicht exportieren
Hintergrund

Bevor man Daten analysiert, muss man verstehen wie sie aussehen: Wie viele Zeilen? Welche Spalten? Wo fehlen Werte? Welche Werte kommen am häufigsten vor? Gibt es Ausreißer die auf Datenfehler oder Anomalien hindeuten?

DataProfiler automatisiert dieses initiale Datenverständnis. Statt Pandas zu importieren und manuell .describe() aufzurufen, genügt ein einziger CLI-Befehl — auch für sehr große Dateien, da der Profiler streamingfähig implementiert wird (ein Pass über die Daten).

Typische Anwendung in der Praxis: Export aus einer Datenbank, CSV vom Kunden, JSON aus einer API — schnell prüfen ob die Daten das sind was man erwartet hat, bevor weitere Verarbeitung startet.

Schlüsselkonzepte

Statistik ohne NumPy

import statistics, math

def column_stats(values: list[float]) -> dict:
    n = len(values)
    if n == 0:
        return {}
    sorted_v = sorted(values)
    q1 = sorted_v[n // 4]
    q3 = sorted_v[3 * n // 4]
    iqr = q3 - q1
    return {
        'count':  n,
        'min':    min(values),
        'max':    max(values),
        'mean':   statistics.mean(values),
        'median': statistics.median(values),
        'stdev':  statistics.stdev(values) if n > 1 else 0,
        'q1': q1, 'q3': q3, 'iqr': iqr,
    }

IQR-Ausreißer

def iqr_outliers(values: list[float], k: float = 1.5) -> list[float]:
    stats = column_stats(values)
    lo = stats['q1'] - k * stats['iqr']
    hi = stats['q3'] + k * stats['iqr']
    return [v for v in values if v < lo or v > hi]

Z-Score-Ausreißer

def zscore_outliers(values: list[float], threshold: float = 3.0) -> list[float]:
    mean = statistics.mean(values)
    std  = statistics.stdev(values) if len(values) > 1 else 1
    return [v for v in values if abs((v - mean) / std) > threshold]

Datentyp-Inferenz

def infer_type(samples: list[str]) -> str:
    non_null = [s for s in samples if s.strip()]
    if not non_null:
        return 'empty'
    numeric = 0
    for s in non_null:
        try: float(s); numeric += 1
        except ValueError: pass
    ratio = numeric / len(non_null)
    if ratio > 0.9: return 'numeric'
    return 'categorical'
Aufgabe — dataprofiler.py
# CSV profilen — tabellarische Ausgabe
dataprofiler.py data.csv

# JSON-Datei profilen
dataprofiler.py events.json --key items  # JSON-Array unter Schlüssel "items"

# Ausreißer-Erkennung per IQR
dataprofiler.py data.csv --outliers iqr --column response_time_ms

# Kompletten Bericht als JSON exportieren
dataprofiler.py data.csv --export report.json

# Nur Null-Anteile anzeigen
dataprofiler.py data.csv --nulls

Ausgabe je Spalte: Name | Typ | Count | Null% | Min | Max | Mean | Median | Stdev | Top-3-Werte

Kein pandas, kein numpy. Das statistics-Modul aus der Stdlib enthält alles was du brauchst. Für Median/Quartile: erst sortieren.

Anforderungen
  • CSV und JSON werden eingelesen und in einheitliches Format überführt
  • Datentyp wird automatisch pro Spalte inferiert (numerisch / kategorial)
  • Statistiken werden korrekt berechnet: min, max, mean, median, stdev, q1, q3
  • Null-/Leer-Anteil wird in Prozent angezeigt
  • --outliers iqr und --outliers zscore sind implementiert
  • --export produziert valides JSON mit dem vollständigen Profil
  • Nur stdlib — kein pandas, kein numpy
Akzeptanzkriterien
  1. Eine CSV mit 100.000 Zeilen wird in unter 5 Sekunden verarbeitet
  2. Spalten mit mehr als 50% Null-Werten werden visuell hervorgehoben
  3. IQR-Ausreißer in einer normalverteilten Testspalte werden korrekt erkannt
  4. Top-3 häufigste Werte werden für kategoriale Spalten angezeigt
  5. Der JSON-Export enthält alle Spaltenprofile und kann von Modul 10 (ForensicKit) weiterverarbeitet werden
