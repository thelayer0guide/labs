Was sind reguläre Ausdrücke?

Hintergrund

Reguläre Ausdrücke (Regex, RegExp) sind eine formale Sprache zur Beschreibung von Zeichenmustern. Sie ermöglichen: Suchen von Mustern in Texten, Validierung von Eingaben (E-Mail, IP-Adresse), Extrahieren von Daten aus Texten, Ersetzen von Teilstrings. Regex wird in fast allen Programmiersprachen und Tools unterstützt: Python (re-Modul), JavaScript, Java, grep, sed, awk, Perl, Ruby.

Im Security-Kontext sind Regex unverzichtbar: Log-Analyse (Muster in Hunderttausenden Zeilen finden), IDS/IPS-Signaturen (Angriffsmuster erkennen), WAF-Regeln (bösartige HTTP-Anfragen filtern), YARA-Regeln (Malware-Muster), Input-Validierung (SQL-Injection, XSS-Filter). Aber Vorsicht: ReDoS (Regular Expression Denial of Service) — bestimmte Regex-Muster können bei bestimmten Inputs exponentiell lange brauchen.

Schlüsselkonzepte

Erste Regex-Schritte

Code anzeigen
# grep mit Regex
grep "error" /var/log/syslog           # Literal
grep "Error\|error\|ERROR" logfile      # Alternativen
grep -i "error" logfile                # Case-insensitive
grep -n "error" logfile                # Zeilennummer
grep -c "error" logfile                # Anzahl Treffer
grep -v "error" logfile                # Invertiert (ohne)

# Python re-Modul
import re
text = "Hallo Welt 42!"
print(re.search("Welt", text))         # Match-Objekt
print(re.findall("[0-9]+", text))      # ["42"]
print(re.sub("Welt", "World", text))   # Ersetzen

# Einfache Literale und Metazeichen
# .   - ein beliebiges Zeichen
# ^   - Anfang der Zeile
# $   - Ende der Zeile
# *   - 0 oder mehr Wiederholungen
# +   - 1 oder mehr Wiederholungen
# ?   - 0 oder 1 Wiederholung
# \   - Escape-Zeichen
Aufgabe

Suche in einer System-Log-Datei nach Fehler-Mustern mit grep und Python re. Extrahiere alle Zeitstempel aus einem Log.

Anforderungen
  1. Regex-Anwendungsfälle in Security nennen (3 Beispiele)
  2. grep mit Literal, -i, -n, -v, -c anwenden
  3. Python re.search, re.findall, re.sub nutzen
  4. Metazeichen . ^ $ * + ? erklären
  5. ReDoS: Konzept und warum es gefährlich ist
Akzeptanzkriterien
  • Fehlermuster in Log-Datei gefunden
  • Zeitstempel extrahiert
  • Metazeichen korrekt erklärt
