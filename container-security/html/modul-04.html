Kubernetes Grundlagen & RBAC

Cheat Sheets
Kubernetes Docker
Lernziele
  • Kubernetes-Architektur (Control Plane, Worker Nodes, etcd) erklären
  • RBAC (Role, ClusterRole, RoleBinding) konfigurieren
  • Service Accounts und ihre Berechtigungen analysieren
  • Kubectl für Enumeration aus Angreifer-Perspektive nutzen
Hintergrund

Kubernetes ist de-facto-Standard für Container-Orchestrierung. Die Komplexität erzeugt viele Angriffsflächen: überprivilegierte Service Accounts, exposed API Server, unsichere etcd-Instanzen.

RBAC (Role-Based Access Control) regelt Berechtigungen in Kubernetes. Fehlkonfigurationen sind häufig: wildcards in Regeln, cluster-admin statt minimaler Rechte, Default Service Accounts mit zu vielen Rechten.

Schlüsselkonzepte

Kubernetes Enumeration

Code anzeigen
# Cluster-Info
kubectl cluster-info
kubectl get nodes
kubectl get pods -A  # alle Namespaces

# Service Accounts
kubectl get serviceaccounts -A
kubectl get rolebindings,clusterrolebindings -A | grep -v system

# Eigene Rechte prüfen
kubectl auth can-i --list
kubectl auth can-i create pods --all-namespaces

RBAC Minimal-Konfiguration

Code anzeigen
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: pod-reader
  namespace: default
rules:
- apiGroups: [""]  # core API group
  resources: ["pods"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: read-pods
  namespace: default
subjects:
- kind: ServiceAccount
  name: my-service-account
roleRef:
  kind: Role
  name: pod-reader
  apiGroup: rbac.authorization.k8s.io
Aufgabe

Analysiere einen Kubernetes-Cluster auf RBAC-Fehlkonfigurationen: finde überprivilegierte Service Accounts, dokumentiere gefährliche ClusterRoleBindings und erstelle minimale RBAC-Rollen.

Anforderungen
  1. kubectl auth can-i --list für Default Service Account
  2. Alle ClusterRoleBindings mit cluster-admin finden
  3. Gefährliche RBAC-Regeln (wildcards) identifizieren
  4. Minimale RBAC-Rolle für eine Beispiel-Anwendung erstellen
Akzeptanzkriterien
  • Mindestens 2 RBAC-Fehlkonfigurationen gefunden
  • Minimale RBAC-Rolle korrekt konfiguriert
  • Service Account Audit vollständig
