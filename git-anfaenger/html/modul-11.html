Git Hooks & Automation

Cheat Sheets
git bash
Lernziele
  • Git Hooks als Automatisierungspunkte im Commit-Prozess verstehen
  • pre-commit Hook zum Ausführen von Linting schreiben
  • commit-msg Hook für Conventional Commits implementieren
  • post-merge Hook für automatische Dependency-Updates
  • Hooks mit dem pre-commit Tool versioniert verwalten
Hintergrund

Git Hooks sind Shell-Skripte, die Git zu bestimmten Zeitpunkten ausführt. Sie sind das Werkzeug, um Qualitätsstandards automatisch durchzusetzen — bevor Code ins Repository kommt.

Das Problem: .git/hooks/ wird nicht versioniert. Das Tool pre-commit löst das: Hooks werden als .pre-commit-config.yaml geteilt.

Schlüsselkonzepte

pre-commit Hook

Code anzeigen
#!/bin/bash
# .git/hooks/pre-commit  →  chmod +x

python -m flake8 .
if [ $? -ne 0 ]; then
  echo "❌ Linting fehlgeschlagen — Commit abgebrochen"
  exit 1
fi

if grep -rn "password\|api_key" --include="*.py" .; then
  echo "⚠️  Mögliche Secrets gefunden!"
  exit 1
fi

commit-msg Hook

Code anzeigen
#!/bin/bash
# .git/hooks/commit-msg  →  chmod +x
MSG=$(cat "$1")
PATTERN="^(feat|fix|docs|style|refactor|test|chore)(\(.+\))?: .{3,}"

if ! echo "$MSG" | grep -qE "$PATTERN"; then
  echo "❌ Conventional Commit Format erforderlich!"
  echo "   Beispiel: feat(auth): login implementiert"
  exit 1
fi

pre-commit Tool

Code anzeigen
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/psf/black
    rev: 23.9.1
    hooks:
      - id: black
  - repo: https://github.com/pycqa/flake8
    rev: 6.1.0
    hooks:
      - id: flake8

# Setup
pip install pre-commit
pre-commit install
pre-commit run --all-files
Aufgabe

Implementiere zwei Hooks manuell: einen pre-commit Hook der flake8 ausführt, und einen commit-msg Hook der Conventional Commits erzwingt. Teste beide mit absichtlich fehlerhaften Commits.

Anforderungen
  1. pre-commit Hook prüft Linting
  2. commit-msg Hook erzwingt Conventional-Commit-Format
  3. Beide Hooks sind ausführbar (chmod +x)
  4. Fehlerhafter Commit wird korrekt abgefangen
Akzeptanzkriterien
  • Commit mit Linting-Fehler wird mit Meldung abgebrochen
  • Commit mit schlechter Nachricht wird abgebrochen
  • Korrekter Commit wird angenommen
