Defensive Security Grundlagen

Cheat Sheets
bash
Lernziele
  • Defense-in-Depth als Sicherheitsphilosophie erklären
  • CIA-Triad (Confidentiality, Integrity, Availability) auf Praxisbeispiele anwenden
  • SOC-Rollen und -Prozesse verstehen
  • Angriffsphasen des Cyber Kill Chain-Modells kennen
  • MITRE ATT&CK Framework als Referenz nutzen
Hintergrund

Team Blue ist die verteidigende Seite der Cybersecurity. Während Red Teams angreifen, verteidigen Blue Teams: sie überwachen, erkennen, analysieren und reagieren auf Bedrohungen.

Defense in Depth (Tiefenstaffelung) bedeutet: mehrere unabhängige Sicherheitsschichten. Wenn eine Schicht versagt, halten die anderen. Kein einzelnes Sicherheitstool schützt allein.

Schlüsselkonzepte

CIA-Triad anwenden

Code anzeigen
# Confidentiality (Vertraulichkeit)
# → Nur Berechtigte lesen Daten
# Werkzeuge: Verschlüsselung, Zugriffskontrollen, NDA

# Integrity (Integrität)
# → Daten werden nicht unbemerkt verändert
# Werkzeuge: Hash-Prüfung, Signaturen, Audit-Logs

# Availability (Verfügbarkeit)
# → System ist wann benötigt erreichbar
# Werkzeuge: Redundanz, Backups, DDoS-Schutz

# Trade-offs:
# Sehr hohe Confidentiality (viele Hürden) → schlechtere Availability
# Sehr hohe Availability (kein Login) → schlechtere Confidentiality

Cyber Kill Chain

Code anzeigen
# Lockheed Martin Kill Chain (2011):
# 1. Reconnaissance   — Ziel erkunden
# 2. Weaponization    — Exploit + Payload vorbereiten
# 3. Delivery         — Payload zustellen (Phishing, Web)
# 4. Exploitation     — Schwachstelle ausnutzen
# 5. Installation     — Persistenz einrichten (Malware)
# 6. C2               — Command & Control Kanal aufbauen
# 7. Actions on Obj.  — Daten stehlen, Ransomware, ...

# Blue Team Ziel: Angriff so früh wie möglich unterbrechen
# Je früher die Phase → desto günstiger die Unterbrechung

MITRE ATT&CK

Code anzeigen
# ATT&CK Matrix: https://attack.mitre.org/
# Tactics → Techniques → Sub-Techniques

# Beispiel: Initial Access
# T1566 Phishing
#   T1566.001 Spearphishing Attachment
#   T1566.002 Spearphishing Link

# Nutzung im SOC:
# 1. Alert kommt rein: "PowerShell lädt Script herunter"
# 2. ATT&CK Mapping: T1059.001 (PowerShell)
# 3. Weitere bekannte Techniken dieser Gruppe?
# 4. Aktiv nach weiteren Indicators suchen
Aufgabe

Analysiere einen öffentlichen Threat-Intelligence-Bericht (z.B. Mandiant M-Trends oder CISA-Advisory). Mappe die beschriebenen Angriffstechniken auf MITRE ATT&CK-Taktiken und erkläre welche Kill-Chain-Phasen abgedeckt werden.

Anforderungen
  1. CIA-Triad auf 3 reale Beispiele angewendet
  2. Kill-Chain-Phasen erklärt
  3. Mindestens 5 ATT&CK-Techniken aus Bericht gemapped
  4. SOC-Rollen (L1, L2, L3, IR) beschrieben
Akzeptanzkriterien
  • ATT&CK-Mapping korrekt (Technik-ID stimmt)
  • Kill-Chain-Phase für jede Technik zugeordnet
  • Remediation für jede Phase genannt
